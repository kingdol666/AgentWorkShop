## Findings

**1. [MAJOR] (p.9, Sec. V-D) The real-LLM loop's autonomy framing conflicts with its own archived transcript.** The paper states the loop is assigned to an agent "whose tool calls the model itself chooses under the platform's operating rules," and that "the model issues the governed write 197.48 °C with an explicit hypothesis." The archived channel transcript (`bench/results/20260917044223-17ho/agent-loop-omp.log`, reproduced in the companion report) shows the task assignment prescribes, verbatim and in order, under "严格按步骤执行" (strictly follow the steps): (1) `daq_query`; (2) `dcw_control` with **value = 197.48** and the **hypothesis string** pre-written; (3) wait 3 s and re-query; (4) `dcw_judge` with verdict **keep**; (5) include the sentinel `INTEGRATED-CLOSEDLOOP-OK` and call `complete_task`. The write value, the hypothesis, the verdict disposition, and the sentinel were all inputs, not model decisions. What the model genuinely contributed — and it is real — is: interpreting the first read as a startup ramp rather than a fault despite the tool's own stale "current 44.65 °C / out-of-window" status line and the injected 190 °C alarm; choosing a 1 s bucket for the first re-query (not in the script); detecting that the 1 s window was stale and adaptively switching to 15 s buckets with a narrower interval; and authoring the evidence citation in the judge record. This is a worthwhile capability result, but the two quoted sentences misdescribe the experiment, and a reader of Fig. 6/Table III will over-attribute initiative to the model. Required: (a) quote or faithfully summarize the scripted assignment in Sec. V-D (or footnote it to the archived transcript, which the reproducibility apparatus already preserves); (b) replace "the model itself chooses" with an accurate statement of what was prescribed vs. chosen; (c) consider relabeling the unit (e.g., "scripted-task real-LLM loop"). Strongly recommended: add one goal-driven variant in which the model derives the setpoint from the board goal rather than receiving 197.48; even n=1 would convert this from an execution test into a genuine (if preliminary) closed-loop decision test.

**2. [MINOR] (p.9–10) The scripted `keep`/sentinel needs one sentence reconciling it with Sec. V-F's own logic.** V-F correctly argues that a matched `CONVERGED` template string is not independent convergence evidence. V-D's completion signal is likewise a model-emitted string (`INTEGRATED-CLOSEDLOOP-OK`) attached to a script-mandated verdict. The defense is available and the paper half-states it ("steps are structured and graded by an oracle sentinel"): the sentinel gates *task completion*, not a score, and it is corroborated by the register readback, the judged record, and the retained transcript. State this explicitly in V-D so the parallel cannot be raised against you.

**3. [MINOR] (p.1, p.7) The deterministic policy behind the agent-team mission should be qualified where the claims are shortest.** Sec. V-D and Table III disclose that the mission's policy is deterministic, but Table I's row ("Agent-team mission — Task-board goal; time-range read; 1 write; attained") and the abstract ("An agent-team mission attains its setpoint objective through the task board and governed tools in one write") do not. Add "(deterministic policy)" in both places so no reader attributes the mission's attainment to an LLM.

**4. [MINOR] (p.7, Sec. V-A) Inconsistent commit semantics between R and E.** For R the paper cites the runtime commit recorded in the archive (d6c824d, matching `env.gitCommit`). For E it cites f45b221, but the 17ho run record itself records `gitCommit = 2b569a7`; f45b221 is the later repository commit that ingested the run artifacts (its message describes adding the P5 trace). Both commits exist, but citing a post-run archive commit for E while citing a runtime commit for R is exactly the provenance ambiguity this paper elsewhere avoids. Cite 2b569a7 for E (or both, e.g., "run at 2b569a7, archived as of f45b221").

**5. [MINOR] (p.7, Sec. V-A) The 55→62 check-count delta is not attributable to the agent units alone.** "Adds an agent-team mission and a real-LLM loop to the integrated profile: 62 passing checks" invites reading 55 + agent units = 62. The fresh no-agent integrated runs have 61 checks, so +6 of the delta is check-inventory growth between commits d6c824d and 2b569a7. One clause ("the check inventory itself grew to 61 in the current build; E adds the agent units for 62") prevents a reviewer-built strawman.

**6. [MINOR] (p.8, p.9) Wording/label inconsistencies.** (a) "24/24 across these four fixtures" — these are four writable protocol stacks within one scenario fixture, not four fixtures. (b) Ablation arm naming: the text uses "ungated" while Fig. 7 labels the same arm "Both disabled"; unify.

**7. [MINOR] (p.9, Fig. 6) Annotation legibility at print size.** Annotations (3) and (4) overlap each other and the recipe-window band; the (3) arrow crosses the PV series near 12:44:15. The figure is otherwise faithful to the transcript (I verified the series point-by-point), so this is presentation only.

**8. [MINOR] (p.10, Sec. V-G) The shipped companion report still prints unannotated invalid verdicts.** The auto-generated consolidated report contains a 16-row REPRODUCIBLE matrix that includes integrated-lane comparisons Sec. V-G explicitly invalidates (e.g., 1bjc-vs-17ho, 61 vs 62 checks, empty map). The ledger documents the withdrawal, and V-G points to the ledger, but a reader who opens the report first will meet the invalid matrix before the caveat. Add a pointer in V-G to the specific ledger entries, or ship the report with a one-line annotation on those rows.

## Recommendation

**MAJOR REVISION.**

The evaluation is measured, not asserted: every deterministic and agent-side number I checked traces to an archived artifact, the evidence units and denominators are stated with unusual care, and the paper invalidates its own weakest historical evidence rather than hiding it. The revision is required because Sec. V-D — the paper's headline new evidence — currently describes a scripted tool-execution exercise in language ("the model itself chooses") that its own archived transcript contradicts; the fix is disclosure and re-scoping rather than new data, but it touches the abstract, Sec. V-D, Table I/III wording, and ideally one additional goal-driven run.

**Top-3 actionable improvements:**

1. **Disclose the scripting in Sec. V-D** (Finding 1): quote/summarize the prescribed task (value 197.48, sequence, keep verdict, sentinel), correct "whose tool calls the model itself chooses," and — most valuable single addition — run one goal-driven LLM variant that must derive its own setpoint from the board goal.
2. **Qualify the mission's determinism at first mention** (Finding 3): abstract and Table I get "(deterministic policy)"; add the one-sentence sentinel-vs-score clarification of Finding 2.
3. **Tighten provenance** (Findings 4, 5, 8): cite the runtime commit for E, state the 55→61→62 check-inventory drift, and annotate or point to the ledger entries for the invalid integrated comparator verdicts shipped in the companion report.
