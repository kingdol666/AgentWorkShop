# Figure 4: route-specific governance

`fig4_route_governance.drawio` is the editable diagrams.net source. `generate.py` rebuilds the vector PDF, SVG, and 600-dpi PNG in the package's central `figures/` folder. The figure compares configured bounds and route-specific checks; it does not claim field safety.

The older `fig3_task_to_write.*` files are retained as a historical alternate from the earlier combined Fig. 3/Fig. 4 source set. They are not used by the manuscript; the active workflow is `figure-sources/fig3/`.
