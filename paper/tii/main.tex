for Industrial Supervisory Control}

\maketitle

\begin{abstract}
Integrating language-model agents into industrial supervision requires more than a connection to an actuator: device semantics, team responsibilities, operating recipes, and execution records must remain associated throughout a control task. This paper presents AgentWorkShop, a configuration-driven framework that couples multi-agent orchestration with industrial acquisition and setpoint execution. Its core services share a logical node and production-run model; external agent engines and storage services remain separate deployment components. Explicit member-to-node bindings determine the tools available to an agent. Agent-issued setpoints pass through mode-dependent approval and execution checks, with readback where supported and attributable operation records. A separate monitor can request bounded compensation; neither an agent verdict nor register readback alone establishes process improvement. The implementation supports five protocol drivers and a registry of fourteen agent engines. Evaluation uses two software plant scenarios, real protocol transports, targeted lifecycle probes, an agent-team optimization mission, and a real-LLM closed-loop execution over Modbus TCP, plus a four-arm mock-driver ablation. The two scenarios reject 24/24 and 9/9 predefined out-of-constraint write attempts, respectively; these are suite-coverage results, not an estimated industrial failure rate. In the cited three-seed run, a fixed non-LLM controller reaches 97.0--97.2\,\% of an offline grid-search reference. An agent-team mission attains its setpoint objective through the task board and governed tools in one write, a real-LLM agent executes a prescribed read--write--verify--judge cycle on a live line with adaptive re-observation and an evidence-cited verdict, and a goal-driven run has the model derive its own setpoints iteratively until a stated thickness target is met and persist the winning recipe; these are single-run capability tests, not optimization-quality comparisons. Four exploratory LLM campaigns expose observation and scoring limitations and are reported separately rather than as a controlled comparison. The evidence supports reusable supervisory integration within the tested scenarios, while exposing the boundaries between authorization, execution, and process-level validation.
\end{abstract}
