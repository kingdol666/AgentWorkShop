\title{A Configuration-Driven Runtime for Integrating Industrial Agents With Online Data Acquisition and Governed Setpoint Operations}

\author{}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{Agent-Mediated Setpoint Control}

\maketitle

\begin{abstract}
Industrial agents need recent process measurements and a controlled path for changing setpoints. We present a configuration-driven runtime that binds production context to distinct acquisition and control signals. Task-mediated agent calls and direct interface calls share a dispatcher that checks authorization and configured limits and revalidates approved requests before dispatch. The runtime records command outcomes, setpoint readbacks, and subsequent process measurements separately. Direct tests of 55 writable endpoints across four simulated scenes and five protocols accepted 220 of 220 admissible requests, rejected 219 of 219 collected out-of-range requests, and matched all 216 available simulator readbacks. In a separate simulated twin, a governed write raised holding pressure from 60 to 63.7~bar with matching readback. A scripted policy yielded lower integrated absolute error than no-write in all nine valid pairs out of eleven in an exploratory batch with an unresolved selection rule. The evidence supports the exercised simulated interfaces and governance routes, not autonomous optimization or physical-plant performance.
\end{abstract}
