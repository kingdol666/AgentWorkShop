# TII 修订复核：采集、控制与复现性

基线：`TII-SUBMISSION-PACKAGE-FINAL/overleaf-source`。本修订在独立目录进行；历史 S7 不改写。

## 原稿判断

- **贡献讲得清楚。** 系统不是新的过程控制器，而是让 Agent 在统一、可审计的应用边界内读取观测、提交有类型的控制意图，并让确定性机制处理权限、审批和写入约束。现稿的方向性绑定、审批后复验和回读分级是有用的工程贡献。
- **数据获取已写在方法里，但未作为实验对象完整呈现。** §III 描述了生产上下文、语义变量、方向、单位和协议映射；§IV 描述了 Agent 先读再提案。原 §VI-A 的五协议数字主要是直接 API 的写接口与读回，不验证 Agent 自己取得了近期时序样本。设备采集器负责取样并落库，`daq_query` 则查询近期已入库观测；两者不能概括为“Agent 直接轮询 PLC”。
- **最高优先级的改进是补关联，不是增加 PASS 数。** 正文应使读者分辨：语义映射是否真实连到仿真协议、Agent 收到了哪段样本、审批批准了哪个对象、写命令是否进入驱动、独立读回是否匹配、之后的 DAQ 是否使用单独时间窗口。单个受控操作验证的是集成链，不是工艺因果、长期闭环或最优性。
- **因果与泛化仍是主要审稿风险。** E6 的有效配对是有限模拟种子，后批选择规则未知，对照是无写入而非工业控制器。E7 的三次终态均低于目标，缺失原始逐条审计日志和服务/模型快照。新试验不得补写成旧 E7 的成功记录，不处理物理投产或设备安全。

## 证据分级

| 类别 | 可回答的问题 | 不能回答的问题 |
| --- | --- | --- |
| S7 归档数据重算 | 留存请求/响应的确切分母、样本积分、排除条件 | 旧实例源、配置、模型与设备是否可原样再建 |
| 有针对性的组件测试 | DAQ 参数、节点可见性、OMP 工具审计、配方预检和模拟驱动分支 | 同一真实模型任务是否串起所有步骤 |
| 新的隔离模拟试验 | 仅限实际留有原始数据和可关联凭据的环节 | 物理 PLC、控制效果、优化收敛、重复成功率 |

## 一条运行如何展示

正文给出一条短时间序列；补充证据保留可连接字段及原值。

1. **采集映射**：变量名、工程单位、协议地址、DAQ 节点、活动批次。
2. **读取**：记录 Agent 工具参数、查询实际时间、窗口、样本数、第一/最后采样时间和原始值；可复算的统计量另列。
3. **控制**：给出另一条参数地址、原设定值、提案目标、审批来源、操作时间和相关的任务/命令标识。审批决策是实验夹具或人工操作则明说。
4. **核验**：分开列出命令回执、独立模拟设备读回和随后采集的过程量。没有逐条证据的步骤标成未证，不能由返回文本或相同数字推断。
