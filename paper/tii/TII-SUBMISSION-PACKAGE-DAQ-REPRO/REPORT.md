# TII 论文修订与复现汇总

## 主要判断

原稿已经描述了数据采集：§III 给出语义变量、工程单位、读写方向及驱动映射，§IV 给出 Agent 获取观测后提交控制意图的流程。原稿的主要缺口在 §VI：直连探针、脚本对照和早期 Agent 试跑之间缺少逐步可追溯的证据。修订稿将“设备采样”“Agent 查询入库数据”“审批下发”“设定点回读”和“过程量随后变化”分别呈现，不把其中一种当作另一种的证明。

## 稿件完成口径

- LaTeX 是投稿主件；Word 是从修订后的同一文本与原 Word 布局同步生成的可编辑衍生件。原 `TII-SUBMISSION-PACKAGE-FINAL` 不变。
- 核心结论限定为模拟环境中的参数映射、治理接口和一条带回读的历史单步调节。没有对自主闭环、物理部署或工艺因果效果作通过判断。
- 隔离实验已经收窗：停模拟线，退出本次应用及模拟器，删除本次容器并确认测试端口释放。下一轮应先留存每个候选数据行及其逐项校验结果；只有通过采样和上下文校验才提交 Agent 任务。在同一任务中关联模型、工具调用、审批、配方运行和写入台账，并显式验证台账 `recipeRunId` 与配方回执一致，再查验独立读回及写后数据。当前复现脚本保留了本轮执行的版本，后续分支并未实测通过。
- 保留的本地 Ultragoal 是工作账本；当前环境未核实原生 Claude `/goal` 停止钩子，不将账本标记当作实验或验收通过。
