\section{Experimental Evaluation}
\label{sec:eval}
We evaluated the configured integration path in one integrated pipeline run.
The run comprised workflow checks, protocol acquisition and guarded writes,
an approval-enabled operation, fixed-seed simulator cases, and a scripted
BOPET task. The results below are grouped by the capability exercised; each
group is a distinct check from the same run.

\subsection{Run Design and Conditions}
\label{sec:eval-protocol}
The run exercised configured task-to-device paths in local deterministic
simulators. A deterministic OpenCode tool adapter invoked platform operations;
no language-model loop or physical equipment was used. The platform and
simulator were already running, and the run reused shared platform data. The
run identifier was
\texttt{20261031034253-1dbo}; Supplementary File~S6 records its reproduction
command, source commit, and selected evidence.

All 17 phase gates passed. Of the 77 checks, 76 passed and one raised a
warning; none failed. The warning came from the BOPET semantic-card check in
P10, while its phase gate passed. Table~\ref{tab:workflow-coverage} summarizes
the checks by workflow block.

\subsection{Protocol Acquisition and Guarded Operations}
\label{sec:eval-protocol-results}
The primary cast-film scene used five simulated endpoints: Modbus TCP,
Modbus RTU, OPC Unified Architecture (OPC UA), Message Queuing Telemetry
Transport (MQTT), and HTTP. The five acquisition nodes returned 54 samples.
Four endpoints also had write-control paths; each received six negative
probes, and the configured write-admission checks rejected all 24. Each
writable path also recorded an accepted legal write. Modbus RTU provided
acquisition only and is excluded from the write-probe count. On the MQTT endpoint,
\texttt{linespeed-sp} maps to the write node and \texttt{thick} to acquisition.
That endpoint returned six thickness samples and recorded one accepted write.
This acquisition/write mapping exercises distinct signals on the same
protocol endpoint.

The run also exercised the human-in-the-loop approval path (P4c). A Line 2
request for 145.5 remained pending until approval returned status 200; the
pending write was then released. The simulated PLC readback was 146, and the
recorded pending-to-approval interval was 452 ms, including polling.

In the same run, the second-scene (\texttt{film-line}) configuration used the
same five protocols and returned 51 acquisition samples. Its three writable
routes each recorded one accepted legal write and rejected three negative
probes. The run report recorded no false block or code change. Table
\ref{tab:protocol-results} compares acquisition and negative-probe counts
across the two scene configurations.

\subsection{Fixed-Seed Simulator Objective Cases}
\label{sec:eval-objective}
The run included three fixed-seed objective cases evaluated against the simulator's
offline reference, $J^*=89.894$. The runner defines $J_{end}$ as the mean of
the last two valid trajectory scores. If a case stops before a second score
is available, $J_{end}$ is the sole valid score. Table~\ref{tab:integrated-seeds}
also lists $J_{last}$, the final individual trajectory score. The $J_{end}/J^*$
ratios ranged from 96.3\% to 98.8\%, with a mean of 97.8\%.

The simulator score is
$J=55J_{\mathrm{thick}}+25J_{\mathrm{quality}}+8J_{\mathrm{energy}}+7J_{\mathrm{throughput}}$.
The thickness term scores deviation from $50\pm2\,\mu\mathrm{m}$ with soft
degradation outside that band; the quality term reflects defect rate, the
energy term screw speed, and the throughput term line speed. The score is
defined only for melt temperature in $195$--$225\,^{\circ}\mathrm{C}$ and
pressure no greater than $22\,\mathrm{MPa}$.

Seed 43 began inside the configured stopping region and therefore required no
iterations or writes; seeds 42 and 44 each used two writes. The offline
reference is a simulator-defined target.
Fig.~\ref{fig:objective-ratios} shows the three case-level ratios; it does not
imply a distribution estimate.

\subsection{Scripted BOPET Integration Trace}
\label{sec:eval-bopet}
One scripted task in the run issued three setpoint writes to three
controls on a biaxially oriented polyethylene terephthalate (BOPET) simulator
scene. The thickness readings were 28.05, 27.98, 27.98, and
$24.84\,\mu\mathrm{m}$; the final reading was inside the configured
$25.0\pm0.7\,\mu\mathrm{m}$ band. The task board marked the task COMPLETED;
its associated parameter-change record remained open and unjudged. The BOPET
phase also raised the single semantic-card warning. Fig.~\ref{fig:bopet-trace}
shows this task separately from the fixed-seed objective cases.
