\section{Related Work}
\label{sec:related}
\subsection{Industrial Agents and Plant Integration}
Industrial-agent research spans natural-language control, PLC programming,
factory skills, shop-floor coordination, digital-twin support, and production
scheduling \cite{biskupovic2025supervision,liu2026agents4plc,wu2025instructmpc,gill2025llmdt,hofmann2025nlc,lim2025llmenabled,zhao2026shopfloor,waseem2026pretrained}.
Plant-facing LLM systems demonstrate complementary forms of integration,
including operator-reviewed OPC UA sequences, module-scoped skills, and
agent-based scheduling (Table~\ref{tab:nearest})
\cite{huang2026made,koehle2026llmdriven,waseem2026pretrained}. These results
motivate frameworks that can host different strategies and equipment
interfaces within a common production workflow.

These systems address useful parts of the integration problem. For example,
K{\"o}hle et al. restrict tool availability by component state and
cross-verify states to expose silent faults in a simulated six-module plant
\cite{koehle2026llmdriven}. AgentWorkShop also treats operational authority
and confirmation as explicit services, within a broader architecture that
coordinates collaborating agents, production objects, analysis, and process
I/O. This distinction is consistent with the safety-aware decision-support
perspective in \cite{jiang2026agentic}; the framework's workflow mechanisms
do not replace process protection or establish operator effectiveness.

\subsection{Production Context, Agent Interfaces, and Automation}
MCP standardizes tool discovery and calls with request-scoped authorization
\cite{mcp2024}, while ISA-88 and ISA-95 provide recipe and operations concepts
\cite{isa88_2010,isa95_2025}. AgentWorkShop uses a reduced production model
and run-to-run discipline \cite{moyne2000r2r} to connect agent tasks to
configured lines, products, recipes, and runs. Software-agent constraints
such as AgentSpec \cite{wang2025agentspec} and CaMeL's capability-based
information-flow control \cite{debenedetti2025camel} address tool behavior
and data flow. The framework combines these concerns with semantic process
quantities, heterogeneous drivers, timestamped observations, and operational
workflows.

Electronic-record governance provides an accountability perspective: FDA
guidance discusses trustworthy records and audit trails \cite{part11}, while
IEC~62443-3-3 specifies industrial system-security requirements
\cite{iec62443-3-3}. Command confirmation also has telecontrol precedents,
including DNP3 select-before-operate \cite{ieee1815dnp3}. Control assurance
methods address state evolution through shielding, control-barrier
functions, and Simplex architectures
\cite{alshiekh2018shielding,ames2017cbf,sha2001simplex}. These mechanisms
complement an integration framework that must resolve which operational
route applies and what evidence it returns. AgentWorkShop focuses on
composing agent collaboration, production context, semantic I/O, and
route-specific operational records so process configurations can change
without embedding every integration decision in each strategy.
