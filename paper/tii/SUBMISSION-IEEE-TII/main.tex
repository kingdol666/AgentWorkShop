\title{Grading Machine-Originated Plant Writes: Separately Inspectable Evidence for Industrial Agent Teams}

\author{Anonymous Authors}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{Grading Machine-Originated Plant Writes}

\maketitle

\begin{abstract}
Large language model (LLM) agents increasingly generate industrial control
changes, yet the safeguards surrounding each proposal---write authority,
active limits, human approval, device acceptance, process
improvement---are rebuilt per deployment inside application code. This
paper presents AgentWorkShop, a governed supervisory execution layer that
turns these concerns into a single path for agent teams: every intervention
is one governed transaction whose admission, approval, actuation, graded
write acknowledgment, verdict, and compensation remain separately
inspectable evidence states. Team identities
reach semantic data-acquisition (DAQ) and write-control (DCW) nodes through
explicit capabilities under a fail-safe line master switch; drivers,
versioned production objects, plugin points, and a typed software
development kit (SDK) form the integration surface, with process models,
objectives, and policies external. The evaluation exercises this path
through protocol-closure and mechanism-ablation drills, agent-team
missions under scripted policies, a deterministic controller loop, and four
concurrent process missions, then stresses it with a deployment-scale
regression campaign on one live multi-line instance. Across seven benchmark
executions all 600 logged checks pass. The evidence grading is falsifiable:
under success-flag semantics the archived failure receipts read success,
and removing the window interlock drops probe interception from 18/18 to
12/18 while the hard range holds at 18/18 in every arm. The evaluation is
simulation-tier; no optimization-benefit claim is made.
\end{abstract}
