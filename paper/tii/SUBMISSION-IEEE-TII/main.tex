\title{AgentWorkShop: A Governed Supervisory Execution Layer for LLM-Agent Plant Writes}

\author{Anonymous Authors}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{AgentWorkShop: Governed Execution for LLM-Agent Plant Writes}

\maketitle

\begin{abstract}
Large language model (LLM) agents increasingly propose control changes on
industrial plants, yet the safeguards surrounding each
proposal---write authority, active limits, human approval, device
acceptance---are rebuilt per deployment inside application code, so a task
reported complete can coexist with a missed process objective.
AgentWorkShop, an open-source governed supervisory execution layer, carries
every agent-originated write along one path: admission against declared,
versioned limits; approval where required; actuation over semantic
write-control nodes; graded
acknowledgment---readback-verified, transport-acknowledged, or
unverified---by what an independent post-write read observes, not the
transport receipt alone; and verdict recording with
compensation---each stage a separately inspectable evidence state
attributed to its originating actor. Team identities reach
data-acquisition and write-control nodes only through explicit
member--node capabilities, prompt content is never admissible as
authority, and a fail-safe-manual line master switch
intercepts approval-free recipe dispatch. Four process
scenarios---injection molding, wastewater treatment, annealing, and
biaxially oriented polyethylene terephthalate (BOPET)
film---and a cast-film reference line exercise the layer across
protocol-interception drills, agent-team missions, and a deployment-scale
regression campaign on one multi-line instance. The evaluation is
simulation-tier (simulator-backed, not physical plants); no
optimization-benefit or safety-assurance claim is made.
\end{abstract}
