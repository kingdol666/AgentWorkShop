\title{A Modular Task-to-Device Integration Framework for Industrial Agents}

\author{}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{Task-to-Device Integration}

\maketitle

\begin{abstract}
Industrial agents must turn task goals into device operations across changing
production contexts and heterogeneous interfaces, while preserving evidence of
both commands and process responses. The platform connects registered agent
harnesses and direct-operation calls to a shared dispatcher. Scene mappings
link semantic controls to configured drivers; command receipts remain separate
from later process observations. When approval is required, the handler checks
that the line, product, recipe, and active run still match the approved
context. In simulation, one registered harness completed six sequential tasks
across two scenes, each with three admitted candidate settings, synthetic
approval, a verified trial receipt, and a run-tagged sample. All six single
post-trial probes fell below their target bands. A mock-driver test rejected
injected stale contexts before writes. Four simulated deterministic
direct-node missions reported final primary values within their target bands
without model-selected
setpoints. These results cover selected configurations; repeatability,
comparative optimization performance, human-review effectiveness, and
physical-plant performance remain unverified.
\end{abstract}
