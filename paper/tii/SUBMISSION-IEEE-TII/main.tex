\title{AgentWorkShop: A Reusable Agent-Team Supervisory Framework for Multi-Scenario Industrial Optimization}

\author{Anonymous Authors}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{AgentWorkShop: A Reusable Agent-Team Supervisory Framework}

\maketitle

\begin{abstract}
Industrial optimization applications are difficult to reuse because task
orchestration, field-protocol integration, production context, execution
authority, and intervention evidence are commonly implemented as
application-specific logic. This paper presents AgentWorkShop, a reusable
agent-team supervisory framework that connects deployed team identities to
semantic data-acquisition (DAQ) and write-control (DCW) nodes through explicit
capabilities, resolves line, product, recipe, and run context at execution
time, and records admission, approval, actuation, readback, process
observation, submitted judgment, and compensation as distinguishable evidence
states. Five protocol families, self-describing node contracts, versioned
production objects, plugin driver interfaces, and a typed SDK form the common
integration surface; scenario-specific models, objectives, guards, and control
policies remain external inputs. A four-question evaluation on real protocol
stacks---governance closure and attribution on five stacks with a four-arm
ablation, agent-team missions on one node and a nine-device line, a
deterministic closed loop against an offline optimum, and four concurrent
process missions---is driven by deterministic external policies through the
governed tools. In the reference run all 83 checks pass: every configured
out-of-window probe is intercepted with no false block, both missions close
their governed loops, and all four missions attain their objective predicates,
while task completion, readback, and attainment remain separately recorded, so
their agreement is evidence rather than a collapsed status. The results support
an inspectable, simulation-tier architecture for reusable industrial
supervisory execution, not a certified safety or autonomous-control function.
\end{abstract}
