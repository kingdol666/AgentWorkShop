\title{AgentWorkShop: A Modular Task-to-Device Integration Framework for Industrial Agents}

\author{}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{AgentWorkShop: Task-to-Device Integration}

\maketitle

\begin{abstract}
Deploying industrial agents across production scenes requires scene-specific
signal and protocol mappings while keeping task context, device dispatch, and
resulting evidence aligned. This paper presents AgentWorkShop, a modular
task-to-device integration framework that composes task adapters, production
context, named operations, semantic input/output, runtime checks, protocol drivers,
and service-owned records. Registered task routes pass through the
collaboration runtime; direct operation calls enter the shared dispatcher
without creating a task record. The design keeps approval, command
readback, and subsequent process observations distinct while linking them to
the active production context. We evaluated registered task paths and direct
operation calls in cast-film and annealing simulators with different
signal and protocol mappings. Six sequential model-mediated task executions and two
fixture-backed command-line tasks preserved their route-specific record
links; direct calls retained operation, readback, and run-tagged sample
records. Every current-route sample remained below its target band. A
mock-state approval-context test refused 12 stale changes before writes,
whereas an ablation allowed six product/run changes through. A separate
v0.8.3 replay of one documented coating-line blueprint passed 23 functional
verification checks and confirmed one simulator write. Together, these results demonstrate
integration behavior for selected preconfigured paths, one simulated onboarding
configuration, and a software dispatch guard. They do not establish process
improvement, configuration reuse, general portability, or comparative platform
benefit.
\end{abstract}
