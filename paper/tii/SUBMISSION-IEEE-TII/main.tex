\title{A Governed Supervisory Execution Layer for LLM-Agent Plant Writes}

\author{Anonymous Authors}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{Governed Execution for LLM-Agent Plant Writes}

\maketitle

\begin{abstract}
\looseness=-1 Large language model (LLM) agents increasingly propose control changes on
industrial plants, yet the safeguards around each
proposal---write authority, active limits, human approval, device
acceptance---are rebuilt per deployment in application code, so a task
reported complete can coexist with a missed process objective.
The platform, an open-source governed supervisory execution layer, carries
agent-originated writes along one path: admission against declared,
versioned limits; approval where required; actuation over semantic
write-control nodes; graded
acknowledgment---readback-verified, transport-acknowledged, or
unverified, with failed as a terminal failure state---by what a
post-write read observes, not the transport receipt alone; and verdict
recording with compensation---each stage a separately inspectable,
actor-attributed evidence state. Team identities reach
nodes only through explicit
member--node capabilities, prompt content is never admissible as
authority, and a fail-safe-manual recipe-dispatch master switch
intercepts approval-free recipe dispatch. Four process
scenarios---injection molding, wastewater treatment, annealing, and
biaxially oriented polyethylene terephthalate (BOPET)
film---plus a cast-film reference line exercise the layer across
protocol-interception drills, agent-team missions, and a nine-run
deployment-scale campaign. Across the archived runs, 33/33 out-of-window
probes are rejected at the attributable layer, a publish-only endpoint that
a success-flag rule would report as successful is graded unverified, and
the campaign completes with zero failed assertions. The evaluation is
simulation-tier; it establishes mechanism behavior and evidence integrity,
not optimization benefit or safety assurance.
\end{abstract}
