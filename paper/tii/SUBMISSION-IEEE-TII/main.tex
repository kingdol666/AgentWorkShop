\title{Configuration-Driven Integration of Industrial Agents Across Production Scenes}

\author{}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{Industrial Agent Integration}

\maketitle

\begin{abstract}
Industrial production scenes expose different process contexts, signal
meanings, and communication protocols, yet task-level agents need a consistent
way to read measurements and issue bounded commands. This paper presents a
configuration-driven architecture that maps line--product--recipe--run
context, acquisition and write-control nodes, protocol drivers, and named
operations. Harness adapters connect agent turns to those operations; a
shared dispatcher checks authority, while route handlers apply scene-specific
limits and approval requirements. Command receipts remain separate from
later process observations. We assessed the configured paths in one integrated
run using deterministic simulators. Five endpoints in the primary cast-film
scene returned 54 samples, and
the write-admission checks rejected all 24 negative probes across four
writable paths. A second scene returned 51 samples and rejected all nine
probes across three writable paths. The 77 workflow checks comprised 76
passes, one warning, and no failures. Three fixed-seed objective cases ended
at 96.3\%--98.8\% of the simulator's offline reference; one case stopped
without an update. The run documents the configured mappings and guarded
operations in simulation. It used no active language-model loop or physical
equipment and did not compare agent harnesses or control baselines.
\end{abstract}
