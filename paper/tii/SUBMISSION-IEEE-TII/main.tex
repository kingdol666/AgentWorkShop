\title{Grading Machine-Originated Plant Writes: Separately Inspectable Evidence for Industrial Agent Teams}

\author{Anonymous Authors}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{Grading Machine-Originated Plant Writes}

\maketitle

\begin{abstract}
Large language model (LLM) agents increasingly propose control changes
directly on industrial plants, yet the safeguards surrounding each
proposal---write authority, active limits, human approval, device
acceptance, process improvement---are rebuilt per deployment inside
application code, so a task reported complete can coexist with a missed
process objective. This paper presents AgentWorkShop, a governed
supervisory execution layer that gives industrial agent teams a single
path for every intervention: admission against declared, versioned
limits, optional human approval, actuation over semantic write-control
nodes, graded write acknowledgment with post-write verification, verdict
recording, and compensation, each left as a separately inspectable
evidence state attributed to a machine actor. Team identities reach
data-acquisition (DAQ) and write-control (DCW) nodes only through
explicit member--node capabilities under a line master switch whose
fail-safe default is manual, so prompt content carries no authority;
protocol drivers, versioned production objects, plugin points, and a
typed software development kit (SDK) keep process models, objectives,
and policies external to the governed path. The acknowledgment grading
is stated so that archived failure receipts and interlock ablations can
falsify it. Four process scenarios---injection molding, wastewater
treatment, annealing, and biaxially oriented polyethylene terephthalate
(BOPET) film---and a cast-film benchmark line exercise the layer across
protocol-interception drills, agent-team missions, and a
deployment-scale regression campaign on one live multi-line instance;
the evaluation is simulation-tier, and no optimization-benefit or
safety-assurance claim is made.
\end{abstract}
