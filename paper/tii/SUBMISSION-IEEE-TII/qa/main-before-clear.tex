\title{AgentWorkShop: A Modular Task-to-Device Integration Framework for Industrial Agents}

\author{}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{AgentWorkShop: Task-to-Device Integration}

\maketitle

\begin{abstract}
Industrial agents need to translate task goals into device operations across
changing production contexts, interfaces, and process constraints. This paper
presents AgentWorkShop, a modular integration framework that connects task and
direct-operation entries to a shared dispatcher, maps semantic controls to
configured device drivers, and maintains command receipts separately from
subsequent process observations. The evaluation combines simulator-based
protocol and node-access checks, tests of records retained by two entry paths,
and a mock-driver test of approval-context revalidation using simulated
decisions. All injected stale contexts in the component test were rejected
before a write. Four deterministic
simulator missions illustrate the operation--observation sequence for injection
molding, film production, annealing, and wastewater treatment. In one trajectory
per scenario, each reported final primary value fell within its target band.
These tests exercise selected integration paths and illustrate process
responses under the tested configurations. The missions do not use a language
model to select setpoints, and the evidence does not establish statistical
repeatability, human-review effectiveness, or physical-plant performance;
some secondary terminal measurements were not archived.
\end{abstract}
