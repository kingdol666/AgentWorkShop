This archival file summarizes a separate supervised agent-to-device test from
an earlier iteration. The test is excluded from the main manuscript results
and is retained only for audit traceability. Its run-level assertion package
and continuous process trace are not available for independent replay. This
summary preserves the recorded order of context retrieval, approval, device
operations, and subsequent acquisition; it is not a complete runtime replay
package.

\section{Configuration}
One acquisition node and three setpoint nodes connected over Modbus TCP to an
isolated gray-box extrusion/casting thermal simulator with first-order inertia
and delay. The simulator was not calibrated against a production line. An
independent Modbus client read its registers. One OMP harness with a local
Qwen model used a manual-approval channel.

\section{Interpretation and Limits}
The archived summary documents one supervised path from production-context and
acquisition queries through an agent-issued recipe trial, manual approval,
Modbus device writes, independent register checks, and subsequent acquisition.
The 2.71\,$^{\circ}$C change was measured in the 40\,s window after the
separate 200-to-205\,$^{\circ}$C step. Because both actions occurred in one
continuous run without an isolated baseline, their residual contributions
cannot be separated. This single test lacks a calibrated process model,
replication, a matched controller, raw model-provider requests and responses,
and a complete environment snapshot; it does not establish process-control
benefit, model reasoning quality, or physical-plant performance.
