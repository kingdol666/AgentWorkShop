\title{Configuration-Driven Integration and Governed Setpoint Writing for Industrial Production Lines}

\author{}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{Governed Setpoint Writing}

\maketitle

\begin{abstract}
Production-line integration must connect process objectives and measurements to the correct control signals while enforcing the authority and limits applicable to each operation. This paper examines that application-level operation boundary through a configuration-driven runtime for agent-mediated and direct setpoint requests. A scene binds line, product, recipe, and run context to direction-specific signal mappings and registered protocol drivers. Calls share a dispatcher whose route handlers apply write admission, conditional approval, and write guards; command outcomes, optional readbacks, and later process observations remain distinct. In simulated probes of 55 configured write-capable endpoints across four scenes and five protocols, all 220 requests with prespecified admissible values received the expected acceptance response and all 219 collected out-of-range requests received the expected rejection. A mock-driver fixture compared configurations with and without a process-window check. In an exploratory fixed-horizon simulator contrast, the scripted policy had lower retained-window integrated absolute error than no-write in all nine selected scene--seed blocks. Initial values were constrained to common windows but not exactly matched, and the batch-selection rule is unresolved. Three language-model-driven injection episodes were canceled below the target band. The work contributes an application-level integration and evidence model; it does not establish a complete agent-to-device write chain, process-control efficacy, autonomous control, or physical-plant safety.
\end{abstract}
