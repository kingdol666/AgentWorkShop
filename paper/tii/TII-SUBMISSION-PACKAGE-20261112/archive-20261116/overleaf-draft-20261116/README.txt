Overleaf draft source package

1. Upload this ZIP as a new Overleaf project.
2. Set `main.tex` as the main document.
3. Select pdfLaTeX as the compiler and BibTeX as the bibliography tool.
4. The package contains all manuscript `.tex` files, the active BibTeX database, and all six figure PDFs.
5. Do not upload generated `.aux`, `.bbl`, `.blg`, `.log`, `.out`, `.synctex.gz`, rendered PNGs, or local session files.
6. Supplementary File S7 and the supporting-evidence archive are distributed separately and are referenced by the manuscript's Data Availability statement.
7. Author identities, affiliations, contribution details, and funding information are intentionally withheld for anonymous initial review and must be restored or updated according to the journal's submission policy before final publication.
