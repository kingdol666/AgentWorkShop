\section{Related Work}

\subsection{Advisory-Boundary Systems}
Industrial LLM applications cluster into advisory families. \emph{Diagnosis and assistance}: CoMA-IKG builds industrial knowledge graphs with LLM agents \cite{zhang2026comaikg}; joint KG--LLM pipelines diagnose aviation-assembly faults \cite{liu2024kgdiag}; surveys chart the breadth \cite{raza2025industrial,ren2025agentic,chen2026largemodels}. \emph{Engineering automation} generates control code: Agents4PLC verifies PLC code against formal specifications \cite{liu2026agents4plc}, as does LLM4PLC via compilers and model checkers \cite{fakih2024llm4plc}; a multi-task LLM system drafts PLC programs \cite{cacciapaglia2026plcmultitask}; MetaIndux-PLC adds control-logic guidance \cite{ren2025metaindux}; embodied multi-agent systems couple LLMs to physical stations and shopfloor scheduling \cite{liu2026embodied,zhao2026shopfloor}, and agent-based supervisors coordinate service-oriented industrial cyber-physical systems \cite{biskupovic2025supervision}. \emph{DT-coupled agents} parameterize simulations \cite{xia2024llmsim}, survey LLM-enhanced twin modeling \cite{yang2025lldt}, and use a twin as prompt source and validation sandbox \cite{gill2025llmdt}. All share two boundaries: output reaches a human or a compiler, never an actuator; and the DT twin is the \emph{destination} of agent action, whereas in \system{} it merely observes a real protocol stack---the destination is the plant. \emph{Closed-loop LLM control}, the newest family, removes the boundary itself: LLM agents have turned fault detections into fault-tolerant control actions on simulated plants \cite{vyas2026ftc}, and tool-equipped LLMs have controlled real machines over OPC UA in natural language \cite{hofmann2025nlc}; in InstructMPC, human instructions reach a model-predictive controller's \emph{predictor} through an LLM in closed loop \cite{wu2025instructmpc}. Adjacent-domain actuation---autonomous chemistry \cite{boiko2023autonomous}, robot control \cite{vemprala2023robotics}, closed-loop code generation for robotic calibration \cite{yoon2025moduloop}---targets single-apparatus loops, not production lines. These works couple one agent (or team) to one protocol stack with per-application governance; none contributes a reusable integration substrate (protocol-heterogeneous, node-native, team-level binding) or a reproducible governed-write benchmark---the gap \system{} fills. The alarm chain of Sec.~\ref{sec:lineops} follows alarm-management practice (ISA-18.2) \cite{isa182}.

\subsection{Governed Execution, Benchmarks, and Frameworks}
Outside industry, $\tau$-bench \cite{yao2024taubench} supplies our approval-gate evaluation paradigm (as does the consequential-task benchmark TheAgentCompany \cite{xu2024company}). Hard action enforcement---control barrier functions \cite{ames2017cbf}, shielding \cite{alshiekh2018shielding}---has its own line; here the wrapped component is an \emph{agent tool surface}, whose fallback path (interlock, approval, readback, journal) is part of the audited contract. Approval semantics rest on levels-of-automation research \cite{parasuraman2000model}. The line/product/recipe/run tree of Sec.~\ref{sec:lineops} combines ISA-95 \cite{isa95} with the ISA-88 recipe/batch model \cite{isa88}; the semantic card is the node-level counterpart of the Asset Administration Shell (IEC~63278) \cite{iec63278}. General agent benchmarks \cite{liu2024agentbench} involve no physical plant or actuator safety contract; industrial datasets (TEP \cite{downs1993tep}, SWaT \cite{goh2017swat}) target fault diagnosis, not closed-loop control---\bench{} bridges the two. Orchestration frameworks (AutoGen \cite{wu2023autogen}, LangGraph \cite{langgraph2024}, CrewAI \cite{crewai2024}; on ReAct \cite{yao2023react}) provide scheduling but no protocol layer, semantic grounding, or write governance; \bench{} defines them as baselines over the same MCP tool surface \cite{mcp2024} in its released protocol. Network segmentation follows IEC~62443 \cite{iec62443}, complementing IEC~61511's basic-control/safety separation \cite{iec61511}; \system{} applies it at the agent--plant layer.
