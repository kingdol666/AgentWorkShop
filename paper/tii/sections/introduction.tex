\section{Introduction}
\IEEEPARstart{I}{ndustrial} enterprises are deploying large language model (LLM) agents widely, with surveys reporting broad adoption \cite{raza2025industrial,sabetta2025assistant}. Yet essentially all published industrial LLM systems stop at the \emph{advisory boundary}. Multi-agent frameworks construct industrial knowledge graphs for fault diagnosis~\cite{zhang2026comaikg}, generate and verify PLC code~\cite{liu2026agents4plc,ren2025metaindux}, and parameterize simulations inside digital twins~\cite{xia2024llmsim,gill2025llmdt}; beyond single-stack control interfaces \cite{hofmann2025nlc} and simulated fault-tolerant control \cite{vyas2026ftc}, in none does an LLM agent team's decision become a governed write on a protocol-heterogeneous plant. These systems share an \emph{integration posture}: the agent is a peripheral that advises a human or a compiler, because no published framework, to our knowledge, integrates an agent team into the plant's own protocol, data, and semantic fabric. The boundary is well motivated---an unguarded write path from a stochastic language model to physical actuators is unacceptable in production---but its consequence is that the central engineering question of agentic industrial automation has never been answered quantitatively: \emph{what does it cost, in integration effort, latency, and human attention, to let an LLM agent team close the control loop on a real plant, and what safety does the resulting governance buy?} This paper measures the first two costs and releases the human-attention arm as a pre-registered protocol design.

This paper argues that the answer requires a framework providing three things no existing work provides together: (i) a \emph{node-native integration substrate} that embeds agent teams into the plant's supervisory fabric---agents, protocol drivers, and plant data share one process and one data domain, so that binding an agent to an actuator is a configuration act, not an integration project; (ii) a \emph{governed write path} that confines the accepted-action language of every agent-issued write to what is safe by construction, attributable, and recoverable, formalized precisely enough to be checked rather than asserted; and (iii) a \emph{reproducible evaluation protocol} that measures both the adaptability of the integration and the safety--overhead trade-off of the write path across protocols, plant scenarios, and fault conditions.

We present \system{}, a configuration-driven \emph{integration framework} that meets all three requirements, together with its evaluation suite, \bench{}. It couples two runtimes that are normally separate products into one process and one data domain: an \emph{agent half} (14 interchangeable LLM harnesses, lead-based team supervision, episodic--semantic memory with hybrid retrieval, cross-channel coordination) and an \emph{industrial half} (five protocol drivers---Modbus TCP, Modbus RTU, OPC UA, MQTT, HTTP/REST---per-node edge acquisition runtimes, a hysteresis-and-debounce alarm chain, and time-series/frame storage). The two halves meet at a \emph{governed bridge}: nodes are bound to agents (individually or as a team), physical semantics are injected as semantic cards (unit, hard safety range, soft recipe window, warn band, freshness) so that agents never see register addresses, and the agent tool surface exposes exactly one write path---the \emph{governed write-control pipeline}, composing a batch-scoped recipe-window \emph{interlock}, a mode-bound human-approval \emph{gate}, a readback-verified \emph{write}, and a signed, attributable \emph{journal}. A system-level \emph{backstop} continuously scores open optimization records against the recipe window and executes bounded, non-destructive rollbacks---at most two consecutive automatic recoveries before mandatory human escalation. Because the agent runtime and the node drivers share one process, this contract is \emph{enforceable} rather than merely declared. Commissioning is configuration, not code: driver configurations are derived at runtime from each plant device's integration export, agent--node bindings and approval modes are declared per node, and a named \emph{plant scenario}---devices, signal semantics, dynamics, recipes---re-instantiates the full deployment; Sec.~\ref{sec:port} measures this claim directly by recommissioning the same live instance onto a second, independently defined plant scenario by switching one scenario identifier.

Our contributions are:
\begin{enumerate}
\item \textbf{A node-native integration framework} for LLM multi-agent teams on heterogeneous production lines: agent runtime and industrial runtime in one process and one data domain; five protocol drivers with per-node edge acquisition; physical-semantic grounding via semantic cards; and team-level node binding under a 14-engine harness registry, so that agent intelligence remains a replaceable component (Sec.~III).
\item \textbf{A governed write-control pipeline} for agent-issued actuator writes, formalized as a supervised state machine with three safety invariants (containment, readback closure, bounded autonomy), each mapped to implementation anchors and negative acceptance tests (Sec.~IV).
\item \textbf{\bench{}}, a reproducible evaluation protocol with a quantified safety--overhead design: to our knowledge the first experimental design that measures interception rate, false-block rate, and write-latency distribution of an approval-gated agent write path, with the human-attention dimension fixed by protocol as E8 (a human-operator approval baseline), against governance ablations, general-purpose agent frameworks, human operators, classical control, and cross-engine replications. The measured arm is reported here (Secs.~\ref{sec:setup}--\ref{sec:e1a}); the remaining arms are released as executable protocol designs. Two quantities are measured rather than asserted: bypassing the soft interlock drops interception from 100\,\% to 66.7\,\%---breach writes execute and are journaled---while no ablation arm adds latency resolvable at this tier, so the cost of governance is structural rather than temporal.
\item \textbf{A completed closed-loop program on a seeded extrusion cast-film line}: a governed controller recovers $J/J^{*}=97.0$--$97.2\,\%$ of the offline grid optimum ($W^{*}{=}89.894$) in two iterations and at most two governed writes per plant seed across three seeds, and four released LLM-agent-team campaigns close the same loop over real transports with every write attributed but reach only a median 76\,\% of that optimum (Secs.~\ref{sec:clbench}--\ref{sec:case}). We report the agent result as a measured negative, because the gap is what motivates the propose/dispose split rather than a claim to be softened.
\end{enumerate}
