\section{Introduction}
\IEEEPARstart{I}{ndustrial} enterprises are deploying large language model (LLM) agents widely \cite{raza2025industrial,sabetta2025assistant}. Yet essentially all published industrial LLM systems stop at the \emph{advisory boundary}: multi-agent frameworks build industrial knowledge graphs~\cite{zhang2026comaikg}, generate and verify PLC code~\cite{liu2026agents4plc,ren2025metaindux}, and parameterize digital-twin simulations~\cite{xia2024llmsim,gill2025llmdt}; beyond single-stack control interfaces \cite{hofmann2025nlc} and simulated fault-tolerant control \cite{vyas2026ftc}, in none does an agent team's decision become a governed write on a protocol-heterogeneous plant---all share an \emph{integration posture}: the agent advises a human or a compiler, never joining the plant's own protocol, data, and semantic fabric. The boundary is well motivated---an unguarded write path from a stochastic model to physical actuators is unacceptable in production---but it has left the central question of agentic industrial automation unanswered quantitatively: \emph{what does it cost, in integration effort, latency, and human attention, to let an LLM agent team close the control loop on a real plant, and what safety does the resulting governance buy?} This paper measures the first two costs and contributes the human-attention arm as a released protocol design.

Answering it requires three things no existing work provides together: (i) a \emph{node-native integration substrate}---agents, protocol drivers, and plant data in one process and one data domain, so binding an agent to an actuator is a configuration act, not an integration project; (ii) a \emph{governed write path} whose accepted-action language is safe by construction, attributable, recoverable, and formalized enough to be checked rather than asserted; and (iii) a \emph{reproducible evaluation protocol} measuring integration adaptability and the write path's safety--overhead trade-off across protocols, plant scenarios, and fault conditions.

We present \system{}, a configuration-driven \emph{integration framework} that meets all three requirements, together with its evaluation suite, \bench{}. It couples an \emph{agent half} (14 interchangeable LLM harnesses, lead-based team supervision, episodic--semantic memory) with an \emph{industrial half} (five protocol drivers, per-node edge acquisition runtimes, a hysteresis-and-debounce alarm chain, and time-series/frame storage); the halves meet at a \emph{governed bridge}. Nodes are bound to agents, physical semantics are injected as semantic cards, and the agent tool surface exposes exactly one write path---the \emph{governed write-control pipeline}: a batch-scoped recipe-window \emph{interlock}, a mode-bound human-approval \emph{gate}, a readback-verified \emph{write}, and a signed, attributable \emph{journal}. A system-level \emph{backstop} scores open optimization records against the recipe window and executes bounded rollbacks. Because the agent runtime and the node drivers share one process, this contract is \emph{enforceable} rather than merely declared. Commissioning is configuration, not code: driver configurations derive at runtime from each device's integration export, and a named \emph{plant scenario} re-instantiates the full deployment; Sec.~\ref{sec:port} recommissions the same live instance onto a second scenario by switching one identifier, with zero platform code changes.

Our contributions are:
\begin{enumerate}
\item \textbf{A node-native integration framework} for LLM multi-agent teams on heterogeneous production lines: agent and industrial runtimes in one process and one data domain; five protocol drivers with per-node edge acquisition; physical-semantic grounding via semantic cards; and team-level node binding under a 14-engine harness registry, keeping agent intelligence replaceable (Sec.~III).
\item \textbf{A governed write-control pipeline} for agent-issued actuator writes, formalized as a supervised state machine with three safety invariants (containment, readback closure, bounded autonomy), each mapped to implementation anchors and negative acceptance tests (Sec.~IV).
\item \textbf{\bench{}}, a reproducible evaluation protocol with a quantified safety--overhead design: to our knowledge the first experimental design measuring the interception rate, false-block rate, and write-latency distribution of an approval-gated agent write path, with the human-attention dimension fixed by protocol as a human-operator arm (E8, Sec.~\ref{sec:bench}), against governance ablations, general frameworks, human operators, classical control, and cross-engine replications; the governance ablation is measured here, the rest are released designs. The measured arm (Secs.~\ref{sec:setup}--\ref{sec:e1a}) shows the cost is structural, not temporal: bypassing the soft interlock drops interception from 100\,\% to 66.7\,\%---breach writes execute and are journaled---with no resolvable latency added.
\item \textbf{A completed closed-loop program on a seeded extrusion cast-film line}: a governed controller recovers $J/J^{*}=97.0$--$97.2\,\%$ of the offline grid optimum ($W^{*}{=}89.894$) in two iterations and at most two governed writes per plant seed across three seeds, and four released LLM-agent-team campaigns close the same loop over real transports with every write attributed but reach only a median 0.76 of that optimum---a measured negative that motivates the propose/dispose split (Secs.~\ref{sec:clbench}--\ref{sec:case}).
\end{enumerate}
