\section{Introduction}
\IEEEPARstart{I}{ndustrial} enterprises are deploying large language model (LLM) agents widely \cite{raza2025industrial,sabetta2025assistant}. Yet essentially all published industrial LLM systems stop at the \emph{advisory boundary}: multi-agent frameworks build industrial knowledge graphs~\cite{zhang2026comaikg}, generate and verify PLC code~\cite{liu2026agents4plc,fakih2024llm4plc,ren2025metaindux}, and parameterize digital-twin simulations~\cite{xia2024llmsim,gill2025llmdt}; beyond single-stack control interfaces \cite{hofmann2025nlc} and simulated fault-tolerant control \cite{vyas2026ftc}, in none does an agent team's decision become a governed write on a protocol-heterogeneous plant. The boundary is well motivated---an unguarded write path from a stochastic model to physical actuators is unacceptable in production---but it has left the central question quantitatively unanswered: \emph{what does it cost, in integration effort and latency, to let an LLM agent team close the control loop on a real plant, and what safety does the resulting governance buy?} This paper measures both costs on a live software instance driving real protocol transports against seeded plant simulators.

Answering them requires three things no existing work provides together: (i) a \emph{node-native integration substrate}---agents, protocol drivers, and plant data in one process and one data domain, so binding an agent to an actuator is a configuration act; (ii) a \emph{governed write path} whose accepted-action language is safe by construction, attributable, recoverable, and formalized enough to be checked rather than asserted; and (iii) a \emph{reproducible benchmark} measuring integration adaptability and the write path's safety--overhead trade-off across protocols, plant scenarios, and fault conditions.

We present \system{}, a configuration-driven integration framework that meets all three requirements, together with its evaluation suite, \bench{}. It couples an \emph{agent half} (14 interchangeable LLM harnesses, lead-based team supervision, episodic--semantic memory) with an \emph{industrial half} (five protocol drivers, per-node edge acquisition, a hysteresis-and-debounce alarm chain, time-series/frame storage); the halves meet at a \emph{governed bridge}. Nodes are bound to agents, physical semantics are injected as semantic cards, and the agent tool surface exposes exactly one write path: a batch-scoped recipe-window \emph{interlock}, a mode-bound human-approval \emph{gate}, a readback-verified \emph{write}, and a signed, attributable \emph{journal}. Throughout, \emph{closed loop} means the supervisory optimization loop---setpoint-level decisions at a seconds-to-minutes cadence; regulatory control remains in the PLCs. A system-level \emph{backstop} scores open optimization records against the recipe window and executes bounded rollbacks. Because the agent runtime and the node drivers share one process, this contract is enforced on the platform-exposed write path rather than merely declared (the containment boundary around the harness engines themselves is a deployment property; Sec.~\ref{sec:hitl}). Commissioning is configuration, not code: driver configurations derive at runtime from each device's integration export, and a named \emph{plant scenario} re-instantiates the full deployment (measured in Sec.~\ref{sec:port}).

Our contributions are:
\begin{enumerate}
\item \textbf{A node-native integration framework} for LLM multi-agent teams on heterogeneous production lines: agent and industrial runtimes in one process and one data domain; five protocol drivers with per-node edge acquisition; physical-semantic grounding via semantic cards; team-level node binding under a 14-engine harness registry (Sec.~\ref{sec:arch}).
\item \textbf{A governed write-control pipeline} for agent-issued actuator writes, formalized as a supervised state machine with three safety invariants---containment, readback closure, bounded autonomy---each mapped to implementation anchors and negative acceptance tests (Secs.~\ref{sec:writepath}--\ref{sec:hitl}).
\item \textbf{\bench{}, an executable benchmark protocol}: seeded, machine-checkable evaluation spanning a static artifact audit, live-instance invariant verification, five-protocol real scenarios, cross-scenario portability, a closed-loop optimization benchmark, and a four-arm governance ablation; frozen baselines and a comparison gate turn reproduction into a machine verdict (Sec.~\ref{sec:eval}). The measured ablation shows the cost is structural, not temporal (Sec.~\ref{sec:e1a}).
\item \textbf{A completed closed-loop program on a seeded extrusion cast-film line}: a fixed deterministic controller (no LLM in the loop) recovers $J/J^{*}=97.0$--$97.2\,\%$ of the offline grid optimum ($W^{*}{=}89.894$) in two iterations and at most two governed writes per plant seed, and four uncontrolled same-seed LLM-agent-team campaigns close the same loop over real transports with every write attributed but reach only 0.35--0.76 (median 0.76) of that optimum---a measured negative that motivates the propose/dispose split (Secs.~\ref{sec:clbench}--\ref{sec:case}).
\end{enumerate}
