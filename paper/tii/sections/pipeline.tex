\section{The Governed Write-Control Pipeline}
This section formalizes the single path by which an agent actuator request becomes a plant write. A \emph{device} is one integrated piece of plant equipment; it appears as one or more \emph{nodes} (instrumented endpoints), and $n$ denotes a \emph{writable} node---one exposing a setpoint, the control image of physical quantity $p$. $n$ carries a hard safety range $S(n) = [n^{\min}, n^{\max}]$ and a value transform $t_n$, and an active \emph{recipe run} $r$ prescribes a process window $W_r(p)$ for $p$. The accepted set is therefore the \emph{effective constraint}
\begin{equation}
C(n, r) =
\begin{cases}
S(n) \cap W_r(p), & \text{run $r$ active},\\[2pt]
S(n), & \text{otherwise.}
\end{cases}
\label{eq:constraint}
\end{equation}
Two independent mechanisms enforce containment: the interlock rejects a value inside $S(n)$ but outside $W_r(p)$, citing the window, while the driver's engineering-quantity validation rejects out-of-range values in every state. Containment thus never depends on authoring-time containment of $W_r(p) \subseteq S(n)$, and both branches of Eq.~\eqref{eq:constraint} are exercised dynamically in Sec.~\ref{sec:dynamic}.

\subsection{Pipeline Stages}
Algorithm~\ref{alg:write} specifies the pipeline: an \emph{approval stage} at the tool boundary, then six ordered execution stages behind the single write entry---approval is a \emph{decision}, execution a \emph{validated act}.
\emph{(0) Approval gate (human in the loop).} On a manually bound node every agent proposal is routed to a human approval request (deduplicated per node and record) and is not submitted further until a human decides; unapproved requests lapse with their record. Approval is decoupled from execution---every later stage re-runs after the decision, so a recipe change during deliberation cannot be exploited through a stale approval. The binding mode selects the posture: \emph{manual} gates as above, \emph{auto} skips the gate but stays subject to interlock and backstop, \emph{unbound} has no write path at all. The gate is a property of the binding model, not a prompt.
\emph{(1) Availability gate.} A paused gateway or disabled node rejects the request: governance is unavailable exactly when actuation is unavailable.
\emph{(2) Closed-loop guardrail.} Agent writes are serialized per optimization scope---one open record per agent, records idle beyond $T_{\text{stale}} = 30$\,min superseded by the next writer---and within a cooldown $T_{\text{cd}} = 300$\,s a same-direction rewrite is rejected while a reverse-direction correction stays allowed, so oscillatory overwrites are impossible.
\emph{(3) Soft interlock.} $v \in C(n, r)$ is checked before any driver interaction.
\emph{(4) Write with readback.} The value is encoded through $t_n$, sent, read back, decoded and compared under
\begin{equation}
\tau(n) = \frac{1}{|t_n^{\text{scale}}|}\max\!\big(0.5 \cdot 10^{-d(n)},\; 0.005\,(n^{\max} - n^{\min})\big),
\label{eq:tolerance}
\end{equation}
the larger of half a least-count digit and 0.5\,\% of span in engineering units ($|t_n^{\text{scale}}|$: transform scale; $d(n)$: display precision). A write is \texttt{ok} only if the decoded readback agrees within $\tau(n)$; a driver that cannot read back yields an explicit \emph{degraded} flag, never a silent confirmation.
\emph{(5)--(6) Journal and audit.} Every executed write appends a signed anchor $(id, line, n, prev, new, \textit{src}, a, r, \textit{approval}, \textit{record}, t)$, and the audit plane receives a typed event attributed to the actor's kind, deduplicated over 10\,s.

\begin{algorithm}[!t]
\caption{Governed write path $\textsc{Write}(n, v, \textit{src}, a)$}
\label{alg:write}
\begin{algorithmic}[1]
\Require node $n$, value $v$, source $\textit{src}$, actor $a$; active run $r$ if any
\If{$\textit{src} = \text{agent}$ $\land$ binding$(n)$ = manual}
  \State route to approval; \textbf{return} pending \Comment{Stage 0; lapse $\Rightarrow$ never executed}
\EndIf
\If{binding$(n)$ = unbound} \State \Return reject(FORBIDDEN) \Comment{tool surface never dispatches it} \EndIf
\If{gateway paused $\lor$ $\neg n.\text{enabled}$} \State \Return reject(CONFLICT) \EndIf
\If{$\textit{src} = \text{agent}$}
  \If{$\exists$ open record $r'$ of $a$ $\land$ $\text{age}(r') < T_{\text{stale}}$} \State \Return reject(CONFLICT)
  \ElsIf{$\exists$ open record $r'$} \State $\textsc{Supersede}(r')$ \EndIf
  \If{same-direction write within $T_{\text{cd}}$} \State \Return reject(CONFLICT) \EndIf
\EndIf
\State $W \gets C(n, r)$ \Comment{Eq.~\eqref{eq:constraint}}
\If{$v \notin W$} \State \Return reject(soft interlock) \EndIf
\State $(\textit{raw}, \textit{rb}) \gets \text{driver.write}(n, t_n^{-1}(v))$
\State $v_{\text{rb}} \gets t_n(\textit{rb})$;\quad \textbf{if} readback unavailable \textbf{then} \textit{degraded} $\gets$ true
\State \textbf{if} \textit{degraded} \textbf{then} $\textit{ok} \gets$ false \textbf{else} $\textit{ok} \gets |v_{\text{rb}} - v| \le \tau(n)$ \Comment{Eq.~\eqref{eq:tolerance}}
  \State $\textsc{JournalAppend}(n, v^{\text{prev}}, v, \textit{src}, a, r, \dots)$ \Comment{executed writes only; approval and record fields elided}
  \State $\textsc{Audit}(\text{write}, n, v, a)$ \Comment{10\,s dedup}
  \State \Return $(\textit{ok}, v_{\text{rb}}, \textit{degraded})$
\end{algorithmic}
\end{algorithm}

\subsection{Backstop and Bounded Autonomy}
An optimization record freezes its pre-write baseline---the parameter value preceding the record's first governed write, with the statistics of the preceding $T_{\text{bl}} = 600$\,s window---and is re-evaluated every $T_{\text{re}} = 30$\,s once older than $T_{\text{win}} = 120$\,s, judged against the active window $W_r(p)$ (falling back to $S(n)$, Eq.~\eqref{eq:constraint}) over every sample acquired since it opened. If the out-of-window count reaches $B = 3$ under an \emph{auto} binding, the system issues a rollback verdict and executes it only while the node's executed-rollback count is below $K = 2$; otherwise the verdict is recorded and escalated to a human. The rollback target defaults to that baseline (finer granularities---stable anchor, batch start, known-good---are operator-invoked), every rollback write traverses this same pipeline, and a paused gateway defers the actuation: the fail-safe direction. Because the counter is per node and monotone, $K$ is a node-lifetime cap.

\subsection{Trust Boundary and Threats}
The pipeline guarantees the \emph{sanctioned} path; no framework constrains software that bypasses it. Harness engines are privileged local processes---a compromised engine could write to the protocol stacks directly, the failure mode \emph{that} indirect prompt injection targets \cite{greshake2023injection}---so the deployment model combines an availability allow-list probe (Sec.~III-C), a least-privilege service account, and IEC~62443 zoning \cite{iec62443} to keep the governed surface the only \emph{reachable} write path, trading zoning isolation for in-process enforceability within one zone. Inside the sanctioned path a prompt cannot \emph{enlarge} an agent's authority; it can only abuse authority the operator already granted, which the approval gate and the chain limit bound. Governance is fail-safe under storage degradation (F6).

\subsection{Safety Invariants}
The pipeline maintains three invariants, each mapped to an implementation anchor and to the platform's scripted acceptance suite:
\begin{itemize}
\item \textbf{I1 (containment).} Every executed agent write satisfies $v \in C(n, r)$ (both branches). \emph{Anchor:} single-entry write function. \emph{Evidence:} rejection-path acceptance tests; live-instance verification (Sec.~\ref{sec:dynamic}).
\item \textbf{I2 (readback closure).} A write is reported \texttt{ok} only if the decoded readback lies within $\tau(n)$ or carries an explicit degraded flag. \emph{Anchor:} Eq.~\eqref{eq:tolerance} in the write executor. \emph{Evidence:} deadband and calibration tests; the no-readback ablation.
\item \textbf{I3 (bounded autonomy).} Automatic rollbacks per node are at most $K = 2$ over the node's life; the third response and all manual-policy rollbacks require human confirmation, and stale records are superseded, never accumulated. \emph{Anchor:} the per-node rollback counter guarding the backstop. \emph{Evidence:} rollback-manager acceptance tests; the backstop drill executes one system-initiated rollback end-to-end, and the escalation-at-$K$ branch is exercised at acceptance-test level (Sec.~\ref{sec:govsurface}).
\end{itemize}
These are stated over the pipeline, not over the LLM: whatever the agent proposes, the accepted-action language is constrained. This is the precise sense in which the system's autonomy is \emph{governed}.
