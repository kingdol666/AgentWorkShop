# R21 deterministic fixture verification

This is a fresh current-version v0.8.0 software-path check in two isolated simulator scenes. A deterministic local OMP-RPC fixture supplies one predeclared recipe-trial call per scene; there is no LLM request or autonomous model decision. Both scenes record a task context, one synthetic approval, a 1/1 readback-verified receipt, and one DAQ sample queried by active-run ID. All 31 runner assertions and 25 isolation assertions pass, including process and port cleanup. R21 does not assert task completion and does not measure process response, quality, convergence, cross-harness portability, or independent simulator replication. It is separate from the six real-agent R20 executions. The runner and fixture source are included here; the runner hash matches the runner retained under R20. To replay, follow `R20/source-snapshot/README.md` to reconstruct the app and simulator, place the included R21 runner and fixture at their recorded repository paths, and run `node scripts/e2e-registered-harness-simulator-paper.mjs` from the app root. The default fixture mode needs the recorded Node dependencies and, on Windows, the .NET Framework C# compiler used for the local process shim; no model credentials are needed. The source reconstruction is conditional and depends on the recorded base revisions and dependencies.
