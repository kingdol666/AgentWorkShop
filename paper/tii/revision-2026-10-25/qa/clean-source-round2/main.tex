\title{AgentWorkShop: A Configurable Framework for Multi-Scenario Industrial Agent Integration}

\author{}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{AgentWorkShop: Industrial Agent Integration}

\maketitle

\begin{abstract}
Industrial-agent applications must integrate collaborative tasks with
production context, heterogeneous equipment, and process data across
configurable manufacturing scenes. AgentWorkShop provides a modular software
framework comprising workspace and task services, registered agent-harness
adapters, scene configuration, line--product--recipe--run context, semantic
acquisition and control nodes, protocol drivers, and analysis and modeling
services. A task turn assembles prompt context and a scoped tool catalog;
each returned operation is checked by a shared dispatcher and routed to its
handler. Industrial routes apply their relevant live-state checks, while
owning services retain available command, approval, observation, and
recipe-version records. We
evaluate the implemented integration paths in cast-film and annealing
simulators. In a two-scene application run, both process-model candidates fail
the configured eligibility gates and are not dispatched. In six sequential
task executions using one registered harness, the model proposes one
prevalidated bounded recipe setting per task; synthetic approval, verified
command readback, and task completion are recorded for all six. Each execution
also produces one run-tagged process sample after a 20-s wait initiated after
task completion; all six samples remain outside their target bands. The
results demonstrate the tested task-to-operation and protocol/data paths in
two scenes, not process convergence, quality improvement, physical-plant
transfer, or cross-harness portability.
\end{abstract}
