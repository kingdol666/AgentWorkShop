\title{AgentWorkShop: A Task-to-Device Integration Architecture for Industrial Agents}

\author{}
\markboth{IEEE Transactions on Industrial Informatics, Submitted Manuscript}{AgentWorkShop: Industrial Agent Integration}

\maketitle

\begin{abstract}
Industrial-agent tasks need an execution path that carries production context
from collaboration services to device-facing operations and keeps command
results distinct from later process observations. AgentWorkShop provides a
modular task-to-device integration architecture that connects workspace and
task services, registered agent-harness adapters, line--product--recipe--run
context, per-call dispatch checks, semantic acquisition and control nodes,
and configured protocol drivers. Prompt context is assembled for each agent
turn; the scoped tool catalog is provisioned with the registered harness, and
operation authority is checked again for each call. Route handlers retain
available command, approval, observation, and recipe-version records in their
owning services. We evaluate two simulator paths in cast-film and annealing
scenes. In R20, six sequential tasks through one registered harness complete
with synthetic approval and verified readback, although all six post-task
samples remain outside target bands. The exploratory R13 application run
records protocol access, readback, and data lineage, while both model
candidates fail the configured gates; its exact runtime source was not
pinned. These results establish the tested integration paths, but not process
attainment or configuration-reuse benefit.
\end{abstract}
