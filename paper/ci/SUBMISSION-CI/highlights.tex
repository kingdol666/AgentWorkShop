\section*{Highlights}
\begin{itemize}
\item Agent write authority becomes a configuration fact bound to plant context
\item Four-layer interlocks attribute every blocked write to its deciding layer
\item Approvals bind exact values and tuples and are rechecked at dispatch
\item Receipts grade writes as readback-verified or transport-acknowledged
\item Ablation: interlock is load-bearing with zero false blocks on legitimate writes
\end{itemize}
