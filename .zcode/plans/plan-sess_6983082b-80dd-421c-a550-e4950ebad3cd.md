## 目标
在保持现有全绿基线（E2E 48/48）与公开 API/事件不变的前提下，把 3D 小镇改造成**面向对象 + 数据驱动**的架构：Channel/Agent/Device 各自封装为 class（属性 + 行为方法），场景加载时按数据库元数据实例化并初始化全部实例，监听动画状态驱动模型与 HUD；同时强化边界拖拽编辑的 UI/UX 并做贴合游戏场景的美工美化。

## 现状与解释
- 持久化即现有 DB 层（不必迁移）：频道布局存 `scene-layouts.repo`(JSON)、Agent home/range/modelRef 存 `channel_agents.config`、设备孪生存 `device-twins.repo`。场景已经在加载时按这些元数据重建（`applySceneLayouts`+`rebuild`+`syncDevices`）；本次把它收敛为**统一的确定性实例化流程**并全部用 class 表达。
- 当前 `Agent3D/Block3D/DeviceNode` 只是 plain object 接口 + 场景巨类中的一堆方法；行为逻辑散在 scene 方法里。

## 改动清单

### 1. OOP 封装（核心，`TownScene3D.ts`）
把三个实体升级为 class（持有 `scene` 反向引用以取跨实体服务：blockLayout/clamp/气泡/事件），行为方法下沉到实体自己：

- **`class Agent3D`**（替换接口）：
  - 属性：channelId/agentId/name/role、root/model/aura/nameSprite/mixer/clips、state/progress/behavior、dragging、homeX/Z、range+rangeLine、bubble/bubbleText、textureKey/modelRef、`animState`。
  - 行为方法：`update(dt)`（FSM：roam/approach/wait/returnHome，目标与步进均按自身 range 钳制）、`driveToward`、`reached`、`playWalkAnim(moving)`（idle/walk 切换 + 无 clip 时 bob）、`setHome`、`setRange`、`renderRangeLine`、`attachBubble/clearBubble`、`mountModel`（GLTF 归一化 + mixer，loader/cache 由 scene 注入）。
- **`class ChannelBlock3D`**（替换 Block3D）：
  - 属性：channelId/name/布局字段/color/platform/boundary/label、`members: Agent3D[]`。
  - 行为方法：`layout()`、`applyPatch(patch)`（重建平台/边界/名牌）、`moveBy(dx,dz)`（整体平移 + members + 各自 range 跟随）、`handlePoints()`、`pointIn(x,z)`、`clampMembersAndRanges()`。
- **`class DeviceNode3D`**（替换 DeviceNode）：
  - 属性：twinId/name/modelRef/root/holder/ring/label/state/telemetry/userScale。
  - 行为方法：`applyTwin(t)`（状态/遥测/改名/换模/transform 收敛）、`updateRingColor()`、`moveTo/rotateTo/setScale`、`rememberTransform()`。
- `TownScene3D` 退化为**导演/控制器**：输入交互（拖拽/手柄/框选/相机）、渲染循环、事件路由、信息接收器、持久化 API 注入，全部改走 class 实例方法。公开接口与事件签名不变。

### 2. 数据驱动实例化 + 动画监听
- 新增 `initializeAll()`：`sceneLayouts.load()`(DB) → entities 快照 → `deviceTwins.load()`(DB)，按此**逐一实例化 ChannelBlock3D/Agent3D/DeviceNode3D 并初始化**（home/range/模型/孪生状态）；后续增量走既有事件同步，仍走统一实例化工厂。
- **Animation 监听**：`Agent3D.animState`（'idle'|'walk'）在 `playWalkAnim` 中切换时回调 scene → 新增 `TownEventMap.motion` 事件（`{ agentName, anim, at }`），HUD/E2E 可订阅；`getDebugState().agents[]` 增加 `anim` 字段（数据驱动模型 → 快照）。
- Device 状态环颜色、Agent 范围线框、气泡 FIFO 全部由实体状态驱动（已是数据驱动，重构后集中在类内）。

### 3. 边界编辑 UI/UX + 美工美化
- **边界/对象面板**：形状分段控件、Radius 滑杆按身份色配色 + 实时数值 chip；Agent 活动范围区块加「范围预览」标尺（当前 矩形/椭圆 尺寸）、框选绘制按钮更醒目的激活态；面板统一玻璃拟态样式、更舒适的间距与 hover。
- **模式栏**：编辑模式加操作提示 pill（"拖拽=移动 · 拉框=Agent 范围 · 手柄=缩放/清除"），吸附开关与保存按钮状态色优化。
- **场景视觉**：Agent 活动范围线框改为**虚线**（LineDashedMaterial 青色）与频道实线边界区分；选中频道平台勾边高亮；面板层级 z 优化避免遮挡。
- **频道坞**：已放置/未放置区分更清晰（色点 + 状态标签），未放置加"拖入安放"引导。

- 新增断言：加载后 `getDebugState()` 中 Channel/Agent/Device 全部实例化且 home/range/模型来自 DB 元数据、`anim` 字段随移动切换、`motion` 事件可订阅。
