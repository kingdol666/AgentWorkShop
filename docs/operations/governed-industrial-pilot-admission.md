# 受治理工业试点独立准入清单（Task 14）

> 状态：**交接包模板，未现场执行**。本文件不产生控制指令、不批准无人值守，也不构成安全认证或 SLA。
> 软件侧结论（Task 13 / 合并主干审计）不能代替本清单；本清单的每一项只能由被授权人员现场完成并签核。

```json
{
  "siteScope": "line:<lineId> product:<productId> recipe:<recipeRevision>",
  "equipmentOwnerRef": "",
  "safetyReviewerRef": "",
  "manualTakeoverEvidenceRef": "",
  "physicalVerificationRefs": [],
```

缺任一签核、任一实物证据或任一韧性门，`status` 必须保持 `BLOCKED`。

## 3. 现场核对清单

- **点位与协议**：设备/点位清单、协议与端口、单位与字节序；S7 等未实现协议不纳入。
- **量程与步限**：节点安全量程、单步限制、保持窗与写入间隔；四层限界交集必须与工艺规程一致。
- **网络与证书**：现场网络段、代理/出站策略、证书与凭据来源（只允许引用，不得写入仓库）。
- **时钟与覆盖**：NTP/时钟偏差、采样覆盖与缺口窗口、断线重连行为。
- **失联与安全**：通信中断、越界写入、急停、手动接管；任何未知写入结果必须人工核对，禁止自动重发。
- **独立观察与回退**：操作员独立读回（非平台自证）、回退步骤与演练记录。
- **MES 边界**：与 MES/上游系统的数据边界与责任划分。
- **恢复负责人**：故障/回退/恢复的负责人、联络方式与升级路径。

## 4. 阶段许可（逐级，不跳级）

| 阶段 | 需要证据 | 不满足时 |
| --- | --- | --- |
| 只读影子 | 点位/量程核对 + 只读采集稳定性 + 独立读回 | 保持只读，禁止任何写 |
| 离线 HIL / FAT | 上述 + 物理设备读写回环 + 急停/接管演练 | 不进入现场写 |
| 现场 SAT | 上述 + 现场安全签核 + 回退演练 + 限定时段窗口 | 不进入生产运行 |
| 生产受控运行 | 上述 + 责任交接 + 经验部署策略（shadow/canary/active）经人审 | 保持前一级 |
