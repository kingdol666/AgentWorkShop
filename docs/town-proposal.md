# 共鸣城邦 · AgentTeam RPG 小镇 — 完整产品策划方案

## 0. 文档定位

本文档是 AgentTeam「小镇」可视化的**产品策划 + UI/UX 设计 + 技术实现**的完整方案。分两部分：

- **第一部分：已落地实现**（本轮已开发并通过端到端验证的功能）；

## 第一部分：已落地实现

### 1. 产品定位

**小镇是多 Agent 作业控制台的「实时可视化戏剧舞台」**——把抽象的 Channel/Agent/事件流，映射成一个可巡视的 2.5D 共鸣世界，让人类经理**一眼看懂**：

- 哪些 Channel 在场、各有多少 Agent；
- 每个 Agent 在闲聊 / 下任务 / 等待回复 / 干完了回归；
- 谁和谁在对话、谁正在忙（进度）；
- 已上传的自定义模型如何落到具体角色上。

**核心价值观**：信息可读优先于炫技，事件可观测、不打扰，运维聚焦优于游戏大杂烩。

### 2. 视觉风格（已定版）

**「共鸣城邦 · Resonance Bastion」**——黄昏调子的 2.5D 斜俯视 diorama。

| 维度 | 落地方式 |
|---|---|
| 构图 | 轻微垂直压扁的斜俯视 + 3 层视差背景（黄昏天空 → 山脊剪影 → 可立足台地） |
| 基调 | 弱化背景（陶土/muted），强化频道功能色 —— 这样高亮区才跳得出来 |
| 频道色 | 沿用 `channelHue` 稳定身份色（HSL 稳定哈希），同频道同色 |
| 光源 | 统一夕阳侧光 + 角色软阴影 + 周身同色共鸣灵光（aura） |
| 角色 | 27.6px 共鸣精魂，4 帧悬停 bob，落地阴影，非"平面贴纸" |

### 3. 世界与空间布局

- **一张连续大坐标世界**（当前 1600×1200），不贴边，四周留足远景。
- **频道 = 共鸣领地**：环形能场（呼吸的 `wu-ring`）+ 地面柔光 + 频道名牌 + 领土描边；频道色由 `channelHue` 稳定决定。
- **角色**在领地内沿中线排布，lead 居中、worker 左右展开；可沿领地半径游走。

### 4. 角色与状态表达

| 状态 | 视觉表达 | 行为 |
|---|---|---|
| idle | 站立 + 缓慢悬停 bob | 领内游走（roam） |
| busy | 头顶进度环 + 进度标签（%） | — |
| stopped | 不运动（静止） | 停止 FSM |
| 被 approach | 驻足配合（engaged） | 暂停游走 |
| 说话/下发 | 头顶气泡 + 事件脉冲 | 头顶气泡消散 |

**行为状态机（标准 AI 控制游戏架构）**：
```
事件 → parseActionFromEnvelope → ActionContext → FSM
idle/roam → approach(跑去下发) → deliver(弹气泡) → wait[需回复]/returnHome[否] → roam
```

### 5. 用户交互模型（已实现）

| 交互 | 动作 | 结果 |
|---|---|---|
| 指挥官镜头 | 滚轮缩放 / 左键拖拽平移 | 自由巡视，不操控角色 |
| 角色拖动 | 按住精灵拖动 | 暂停 FSM，**落点 = 新 home**（事后回归该位） |
| 模型拖放 | 从模型库拖到场景 | 落在角色上→**换装**；落空地→**生成居民** |
| 点选/聚焦 | 深链 `?view=town` 自动聚焦频道 | 镜头居中 |

### 6. 模型库 → 场景（拖拽加载，本轮重点）

**链路**：
```
模型库卡片(dragstart 写 dataTransfer assetId)
   → 场景 canvas(dragover/drop)
      → dropModelOnWorld(worldX, worldY, assetId)
         → 就近 80px 内角色? 换装(swapTexture) : 落点生成居民(spawnResident)
```

- **支持形态**：精灵表（48×88，4 帧悬停 bob），与内置精魂同帧布局，复用同一套 `wu-bob-<key>` 动画。
- **换装**：`setTexture` + 重播动画 + 记录 `modelRef`，气泡提示"换装 → 模型名"。
- **生成居民**：无 Channel 绑定的装饰角色（可拖动、可游走），带中性柔光 + 名牌。
- **数据**：`AgentView.modelRef` 透传；`buildTownInput` 携带；`getDebugState()` 暴露 `textureKey/modelRef/decorated` 供断言。
- **素材落地**：`public/assets/game/character/*.png`（本轮由 `scripts/build-character-models.mjs` 生成 3 个原创模型：骑士/法师/机甲），场景 `preload` 预载，纹理在 `create` 前就绪。

### 9. 数据面（已就绪，零改动）

```
useWorkshopWs.ingest → events/entities store + useTownBus.emit(每帧 AEP 旁路)
  → TownScene.handleTownEvent → 气泡/状态/进度 + 行为 FSM
```
- 旁路广播幂等，注释一行即完全回退。
- 与时间线/lanes/board/split 四个视图解耦，互不影响。

### 10. 完整分阶段路线（P1→P6）

| 阶段 | 交付 | 验收 |
|---|---|---|
| **P1 世界形态** | 大坐标世界地图（建议 3200×2400）；频道沿道路环形/带状任意布点；街区间道路样条；沿路寻路移动；y-排序 | 多频道成环形城邦；角色沿路走到对方面前 |
| **P2 2.5D 造型** | 视差背景分层；建筑顶面+侧壁挤出；统一方向光；落地阴影细化 | 截图有明显的纵深与体积感 |
| **P3 渲染解耦** | `assets.ts` 模型解析纯函数；内置精魂与自定义模型走同一 `anims` 接口 | 内置/自定义都能播状态动画 |
| **P4 素材上传** | AssetLibrary + 上传接口 + 注册表 + 校验/预览/引删保护 | 上传单帧/sheet/zip → 渲染 → 绑定到 agent |
| **P5 绑定** | 按角色/角色类型/频道三粒度绑定；换装即时生效；缺失回退内置 | 换装正确；非法素材有提示不白屏 |
| **P6 事件共通打磨** | 说话脉冲/交付档案+握手/完成光柱/错误红涟漪/HUD 事件跑马灯；色盲符号；性能压测 | 8 频道同屏流畅；lint/tsc 干净 |

### 11. 模型上传管线设计（P4 重点，产品建议）

**上传（前端）** → **校验+落盘（服务端）** → **注册表** → **绑定** → **渲染**。

```
新增服务端:
  POST /api/workshop/assets/character  (multipart: 校验 png/gif/webp/zip + 尺寸允许 + 像素读取)
  GET  /api/workshop/assets/character  (列表/删除, 引删保护: 被 N 个 agent 绑定时提示停用而非硬删)
  PATCH /api/workshop/channels/:cid/agents/:agentId  (body: { modelRef })
新增前端:
  AssetLibrary(扩展: 上传/预览/绑定)
  useCharacterAssets(扩展: 拉取资产列表 + 上传)
  assets.ts(模型→纹理/动画解析, 纯函数可测)
数据模型:
  CharacterAsset { id, workspaceId, name, file, kind(single|sheet|zip), sheet?, anims?, anchor?, scale?, author, createdAt, appliedTo[] }
渲染绑定:
  modelRef → 纹理 key → 单帧 add.image / sheet 播 anim / zip 按状态切 anim
  缺失/非法 → 自动回退内置精魂, 永不白屏
```

### 12. 风险与取舍

- **"太游戏化抢运维"**：所有视觉响应服务可读性；事件不弹窗；信息密度优先。
- **性能**：粒子/光柱/大图 → 纹理缓存 + 池化 + 可视区剔除 + 缩放警告。
- **色盲**：频道用「颜色 + 几何徽记」双通道编码，不单靠色相。
- **索引冲突**：街区任意布点后需防重叠 → 程序化布点 + 拖拽吸附 + 碰撞提示。
- **资产安全**：白名单 mime + 尺寸上限 + 像素校验；不与可执行脚本混用。
- **回退**：数据面仅一行 `townBus.emit`；素材库为增量功能，禁用即回退内置。

### 13. 一句话总结

把小镇升级为**「一张连续平面大世界上的 2.5D 共鸣城邦」**：用斜俯视 + 视差 + 阴影 + 建筑挤出做出立体感，用**自由视角相机**做指挥官式监测，并新增**一套角色模型导入管线**（拖拽加载 → 换装/生成居民 → `modelRef` 持久化 → `getDebugState` 可断言），让每个 Agent 都能换成用户自定义模型在场景中渲染。核心交互（拖拽换装、全部 Agent 落地、可拖动、同频道同色光）已实现并通过端到端验证。
