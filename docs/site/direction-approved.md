## 迭代 3(2026-09-02 晚):第一屏信息密度 + 声部对齐 + 可读性收敛

仍在已批准方向内深化(同一豁免依据:已选定方向后的迭代,不重开三方向)。骨架不变,五处改动:

1. **第一屏说清「是什么 / 给谁用 / 凭什么值」。** hero 增加定位三连(mono 铭牌 + 正文),
   CTA 收敛为三级(实心绿主 / 面板次 / 安静文字第三),其下紧跟 FIG.00 管线示意与
   **6 格真实数字带**(5 协议 / 4 入口 / 14 引擎 / 99 设置项 / 124 断言 / 7 态任务机),
   并附一行读数口径说明 —— 每个数字都能在仓库里数出来。
2. **主视觉动起来(示意,不伪装实况)。** 脉冲重写为纯 transform 的"行走器"
   (0 高度容器平移 100% - 7px,圆点画在 ::after 上),新增青色流光扫描线,
   节点按内联 `--i` **逐个通电**。全部动画写在 `prefers-reduced-motion: no-preference` 之内
   —— 衰减是"选择加入"而不是"记得关掉";`reduce` 下脉冲停在轨道终点,读作"信号已抵达"。
   轨道标题标注"(走向示意)",不暗示实时数据。
3. **声部与产品对齐。** 产品 `app/assets/css/main.css` 的 `--font-display` 是衬线(编辑部声部):
   EB Garamond + Songti/SimSun 回退。文档站此前把 h1 设成 `--aw-mono`,但中文根本不进
   Cascadia 字形表,实际落到 `Microsoft YaHei`,且等宽空格(1ch ≈ 0.6em)在「Agent」与
   「团队」之间撑出一个洞 —— 等于"中文其实是无衬线,而且间距是错的"。
   新增 `--aw-serif`(**不下载任何字体**:EB Garamond → Noto Serif SC → Source Han Serif SC →
   Songti SC → STSong → SimSun → Georgia → serif),标题衬线 / 正文无衬线 / 数字与铭牌 mono。
4. **真实界面成节。** 新增「01 真实界面」,三张实例截图(town / daq / line-ops)以仪表框呈现:
   发丝边 + 面板标题栏 + FIG 编号 + **四角注册角标** + 框内说明题
   (说明题不再用 `margin: -16px` 在框外悬空)。新资产 `public/daq.png` ← `docs/readme-assets/daq.png`。
5. **可读性收敛(全部为实测,不是目测)。**

   | 指标 | 基线 | 迭代 3 |
   |---|---|---|
   | WCAG AA 对比度失败(6 页 × 4 档) | 4 处(全在首页) | **0** |
   | 最小文字 | 10.5px | **12px**(标签)/ 13px(说明)/ 15px+(正文) |
   | 横向溢出 1440 / 1024 / 768 / 390 | 0 | **0** |

   三处具体修正:
   - `--aw-faint` #6f7f96 → **#7a8ba3**。旧值对 `--aw-bg` 4.92:1、对 `--aw-panel` 4.61:1 尚可,
     但对 **`--aw-panel-2` 只有 4.35:1** —— 而 `hw-node` / 控制台标题栏 / 侧栏激活态正是 panel-2,
     于是"最淡的一级文字"恰好在它最常出现的表面上不达 AA。新值三面分别为 5.67 / 5.31 / 5.01。
   - `.hw-p .no`(22px 装饰序号)用 `--aw-line-hi`,22px/700 属大文本只需 3:1,而它只有 **1.90:1**
     (≈不可见)。新增令牌 `--aw-num` #55719a = 3.70:1:看得见,但仍退居内容之后。
   - `.hw-layer.hw-sub .l2` 此前写的是 `--aw-ghost` —— 而该令牌在 custom.css 第 21 行被明确定义为
     "纯装饰色,**不得用作文字颜色**"(3.80:1)。改回 `--aw-faint`。

   **响应式母题不中断**:基线层在 ≤960 直接把轨道线/刻度/脉冲 `display: none`(横向 6 列变 3×2),
   母题在小屏就断了。改为 ≤960 时轨道转**纵向列**:竖轨 + 竖直行走的脉冲 + 竖直流光;
   ≤420 数字带转 1 列,并把每格改成"名左 / 值右"的读数行(6 格竖排过高)。

   **两个反直觉的坑(已写进 CSS 注释):**
   - `.aw-console` 必须显式 `position: relative` + `overflow: visible`。缺前者时角标的
     `right: -6px` 会锚到初始包含块,`scrollWidth` 被撑大 6px;缺后者会被基线层的
     `overflow: hidden` 整条剪掉。
   - 首页容器放开后(`:has(.hw-hero)` → `max-width: none; padding: 0`),VitePress 在 ≤639px
     给代码块的 `margin: 16px -24px` 失去对消对象 → 净溢出 6px。需把它对齐成 `.hw-wrap` 的 18px。

   **markdown 约束(写进两个首页的顶部注释):** HTML block 在空行处终止,空行之后缩进 ≥4 空格的行
   会被 markdown-it 当作**缩进代码块**转义输出,构建期报 "Element is missing end tag"。
   块级元素一律 ≤2 空格缩进。
