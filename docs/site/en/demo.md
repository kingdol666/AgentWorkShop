## What the video shows

The walkthrough moves from the control-room dashboard and live telemetry into the EDA analysis pipeline (import → code post-processing → chart → template), then through governed line operations, the published ontology, the agent workshop, the plugin surface, the analysis ledger, and the EDA chart gallery. The narration is in English; the player offers English and Simplified Chinese captions.

This recording uses an isolated local environment with mock device drivers; telemetry is replayed by a 1 Hz sampler during capture, and write-governance is shown through read-only UI. No physical PLC is connected and no control write is issued to real equipment. The footage demonstrates the product interface and workflow; it does not present a live factory run.

Narration was generated with the Edge neural voice `en-US-AndrewNeural` at -4% rate; every bilingual caption was authored and reviewed per sentence. Footage is real screen capture (CDP screencast, 1920×1080, light theme). A [standalone player page](/demo/player.html) is also available.
