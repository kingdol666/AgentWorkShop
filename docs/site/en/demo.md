## What the video shows

The walkthrough uses the English interface: control-room dashboard, live telemetry, the EDA analysis pipeline (import → code post-processing → chart → template), the governed tool catalog, the published ontology, four agent workspaces, the plugin surface, the analysis ledger, and the EDA studio. The narration is in English; the player offers English and Simplified Chinese captions.

This recording uses an isolated local environment. The line and control nodes use mock device drivers, and telemetry is generated by the mock DAQ driver at 1 Hz. The analysis records and ontology are seeded demo data used to show the interface and workflow. No physical PLC is connected and no control write is issued to real equipment. The footage does not present a live factory run.

Narration was generated with the Edge neural voice `en-US-AndrewNeural` at -4% rate; every bilingual caption was reviewed per sentence. Footage is real screen capture (CDP screencast, 1920×1080, light theme, English UI). A [standalone player page](https://kingdol666.github.io/AgentWorkShop/demo/player.html) is also available.
