### 截止报告时受阻(附证据链)
③ 产线运营及后续区块被**间歇性连接重置**阻塞:ECONNRESET → goto 挂起 → 外层 timeout。证据:4 次运行四种失败签名(截图超时 300s+/goto 60-120s 超时/login ECONNRESET),而**同一时刻 curl SSR 探测 0.23-0.28s×3 全通**、健康门正常——服务端渲染正常,故障在浏览器↔服务器连接层。归因:本机同时承载 4 个服务 + 2 个模拟器 + 多个 omp agent 进程,负载下 Windows 回环连接间歇重置;非应用代码缺陷(dev/prod 双模式均复现)。缓解建议:独占空载机器或分节段运行(已验证 ①② 可稳定通过)。

## 2. 已修复并推送的本轮缺陷(10c7a8d)

1. **e2e 脚本硬编码凭据**(admin@awshop.local/admin123 在任何真实实例必失败)→ `AW_EMAIL/AW_PASS` 参数化
