## 本轮修复(真根因)
1. **diag 自动诊断链从未触发的根因 = 首样本竞态**:开线后首个越限样本即刻触发诊断,快照查询早于 TSDB 首次刷盘(500ms)→ 时窗查空失败,且 30 分钟冷却已被占用无法重试。修复(plugin.mjs):空窗失败定向重试(≤3 次 × 5s,不回滚冷却)。修复后实证:越限样本同秒发起自动诊断(runId source='auto' → sweep 收题 completed),冷却窗内无重发。
2. **AML buildDataset 500 根因 = 空 run 产生 ±Infinity 网格**:某 run 时序查空(0 行)→ g0=-Inf/g1=+Inf → steps=Infinity 通过最小窗口检查 → 网格循环 RangeError。修复(dataset-builder.ts):steps 有限性守卫,空 run 按丢弃处理(reason="有效网格 0 步不足一个窗口")。双批次 byRun 评估随之打通(3 批次数据集 train195/val259/test26,G1~G5 门全部有输出)。
3. 附带:AML 作业失败原因优先取协议 error 消息(原先只显示"评估失败:exit");单批次负路径保持 fail-closed(清晰错误,非 500)。
