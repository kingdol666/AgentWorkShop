写入与读任务分离：管理员另行将 SP 从 25 写到 27，再恢复到 25；独立 DAQ 两次读到 27 和 25。该写入没有 Agent task、actor、approval 或 driver-event 关联，不能称为 Agent 参数下发闭环。HTTP 返回的 readback-verified 是响应回显，设备证据来自独立 DAQ。
