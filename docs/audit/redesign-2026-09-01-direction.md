## 仪表盘 form 五问

1. **叙事角色**:hero(落地页门面)+ 数据/监控正文。双重身份:对外是产品 landing,对内是运营大屏。
2. **观众距离**:1m 笔记本/投屏。KPI 数字大、图表中等密度、层级靠 surface 阶梯而非重装饰。
3. **视觉温度**:冷静权威(夜航仪)。深海军蓝玻璃 + 品牌绿唯一主动作 + 数据青信息色。
4. **容量估算**:hero(~210px)+ KPI 六卡(~92px)+ 图阵两行(~560px)+ 产线清单(封顶 ~430px,
   溢出交给出入口)。现库内 94 条产线(绝大多数为测试残留),**必须裁策**:运行中优先 + 最近活跃,
   最多展示 8 卡,余量聚合为「全部产线」入口 —— 清单是导航,不是数据库导出。
5. **视觉母题**:「产线脉搏」—— 等宽 tabular 数字 + LIVE 呼吸点 + 量程归一化流动趋势线。
   母题来自内容:控制室的仪表读数与示波器扫描。落点:hero LIVE 卡、趋势图、KPI 数字体。

## /town form 五问(要点)

1. 叙事角色:全屏控制室 HUD(工具型),3D 舞台是唯一主角。
2. 观众距离:0.5–1m,高密度,但装饰为零。
3. 视觉温度:夜航仪冷静;状态色只表语义。
4. 容量:底坞趋势卡 52 路 chip 墙(两行封顶仍是噪音墙)+ 52 条曲线叠绘成 spaghetti;
   右轨健康环 100% 却显琥珀(分布环与健康度语义打架)。
5. 母题:HUD 仪表 + callout 引线。

### 落点(克制清单)
- 趋势信号条:默认仅显前 8 路在采通道,余量折叠为「+N」展开(滚动细轨);曲线同步只画可见路 —— 数据可读性优先。
- 健康环:中心百分数按健康分档着色(≥90 绿 / ≥60 琥珀 / <60 红),环保持状态分布语义,图例已解释。
- 其余不动(左轨/Inspector/KPI 条已符合宪法)。

## 动画机会门控(find-animation-opportunities)

候选 → 门控结果:
- 仪表盘 KPI 数字滚动(tableau 滚数)→ **拒**:数据每 5s 刷新,持续动画=持续噪音,妨碍读数。
- 趋势图入场画线动画 → **拒**:功能性数据,用户在读;装饰有碍。
- 产线清单卡片 hover 浮起 → **已有**(aw-tile/tile hover),无需新增。
- fleet 卡入场 stagger → **已有**(aw-stagger),保留。
- LIVE 呼吸点 → **已有**(livePulse 1.6s),保留。
- hero CTA 按压反馈 → **已有**(.aw-pill:active scale 0.97)。
- **收**:town 趋势「+N」展开/收起 → height+opacity 过渡 240ms ease-out(状态指示,occasional 频次,预算内)。
- **收**:仪表盘「全部产线」入口 hover 位移箭头 160ms(im-nudge 已有体系,挂现成类)。

结论:该界面动效已接近正确量,新增仅两处状态过渡,其余全部复用既有体系。
