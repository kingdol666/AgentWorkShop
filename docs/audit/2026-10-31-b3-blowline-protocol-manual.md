## 2. 数据采集接口(读侧)

### 2.1 HTTP 轮询

**P1 熔体压力 PV**

```
GET /api/v1/melt/pressure
→ 200 {"code":0,"data":{"pressure":23.5,"ts":1730360000000}}
```

- 采样周期:**1000 ms**
- 量程:0 ~ 50 bar;单位 bar;精度 0.01 bar
- 方向:只读(PV,禁止写)

**P2 瓶坯温度 PV**

```
GET /api/v1/preform/temp
→ 200 {"code":0,"data":{"temp":105.2,"ts":1730360000000}}
```

- 采样周期:**未注明**(厂家建议 ≤5s;具体由客户工艺确定 —— **未决事项 B-1**)
- 量程:0 ~ 300 ℃;单位 ℃;精度 0.1 ℃
- 方向:只读(PV,禁止写)

### 2.2 MQTT 遥测(环境段)

**P3/P4 环境温湿度(同报文多字段)**

```
topic: aw/blow/b3/env   (周期 2000 ms,无 retain)
payload: {"temp":22.3,"humidity":52.1,"ts":1730360000000}
```

- 温度:0 ~ 60 ℃,精度 0.1;湿度:0 ~ 100 %RH,精度 0.1
- **温度与湿度在同一条报文内**,消费方按字段拆分;两字段入库时间戳必须重合(验收判据 §7-2)

## 3. 控制接口(写侧)

### 3.1 模头温度 SP(HTTP)

```
PUT /api/v1/head/temp/sp
body: {"sp":210.0}
→ 200 {"code":0,"data":{"sp":210.0,"applied":true}}
```

- 量程:150 ~ 260 ℃;精度 0.1 ℃
- **单步上限 ≤2.0 ℃**(厂家工艺联锁,超步设备拒收)
- 两次写变更间隔 ≥1s
- 应答即应用确认:`applied=true` 表示设备已接受;集成方应以**应答读回值**作为证实

### 3.2 吹气压力 SP(MQTT)

- **命令下发**:publish `aw/blow/b3/cmd/pressure`,payload `{"sp":2.60}`;QoS 未注明(厂家建议 QoS1 —— **未决事项 B-2**)
- **应用确认**:设备应用后(延迟 <1s)publish `aw/blow/b3/sp/pressure`,payload `{"sp":2.60,"applied":true,"ts":...}`
- 集成方必须订阅确认主题做**独立回读证实**;仅命令发布成功(transport-ack)不得视为写成功
- 量程:0 ~ 4.00 bar;精度 0.01 bar
- **单步上限:由客户工艺确定**(**未决事项 B-3**);**两次变更冷却时间:未注明**(**未决事项 B-4**)

## 5. 工况与安全约束

- 吹气压力 ≥3.6 bar 触发高压联锁,设备自动泄压并报警 —— 远程设定不得越过 3.0 bar 预警线(厂家建议,可作为写控 max 参考)
- 模头温度 <180 ℃ 时禁止高压吹气启动(联锁,信息性)
- 环境湿度 >70 %RH 需除湿干预(信息点,不联锁)
- 所有写侧动作必须留痕:谁、何时、写前值、写后值、证实方式

## 6. 选配:瓶身壁厚截面向量(P5)

```
GET /api/v1/wall/profile
→ 200 {"code":0,"data":{"points":[1.82,1.83,...],"ts":...}}   (16 点)
```

- 16 点周向壁厚截面,单位 mm,量程 0.8~3.0,精度 0.001;建议采样周期 5s
- **是否一期接入由客户确定**(**未决事项 B-5**);一期不接入不影响其余点位验收

## 7. 验收判据(合同)

1. 每个接入点连续 ≥3 个采样周期有新样本,值落在文档期望带内;
2. P3/P4 两字段来自同一报文,入库时间戳重合(同一 `ts`);
3. S1 写后:HTTP 应答 `applied=true` 且应答读回值 = 写值;
4. S2 写后:确认主题报文值 = 写值,且独立订阅该确认主题的采集点可见同值 —— 仅 transport-ack 不判成功;
5. 导出 CSV 行数与采样周期吻合、时间戳单调在窗、`line_id` 归属本次接入线。
