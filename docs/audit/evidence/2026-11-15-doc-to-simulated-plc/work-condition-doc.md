# 精密注塑克重闭环验证线 — 工况开发文档

> 文档编号：WC-INJ-2026-1115  
> 版本：v1.0（测试夹具口径）  
> 用途：AgentWorkShop「工况文档 → 模拟 PLC → 平台接入 → Channel 作业 → 闭环控制 → 割接演练」验收。  
> 说明：本文所有量程、单位、因果系数均为**测试夹具参数**，不是物理产线标定结论；模拟结果不能替代物理 HIL。

## 1. 产线目标

- 产线：精密注塑克重闭环验证线。
- 产品：PP 家电面板。
- 质量目标：制品克重 **32.50 ± 0.35 g**；飞边 ≤ 0.4%；表面缺陷率 ≤ 0.5%；模具温度 50–60 ℃。
- 控制目标：在安全限内调整保压压力/保压时间，使克重进入目标窗口，同时守住飞边、缺陷率与模温。
- 作业方式：Channel 闭环优化（manual/HITL 治理；测试期自动裁决，投用须人工 judge & taste）。

## 4. 采样与写入节拍

- DAQ 采样：1000 ms；平台按 5 s 桶查询。
- DCW 写入：最小间隔 60 s；保压压力单步 ≤2 MPa，保压时间单步 ≤0.5 s。
- HITL：所有 DCW 写入必须审批；测试期由验收脚本自动裁决，正式投用由产线负责人裁决。
- 越界：任何超出量程或活动配方窗口的写入必须 400 拒绝，不得到达模拟器。

## 5. 闭环策略（测试口径）

1. 读取 `partWeightPV` 最近 2–5 min 均值。
2. 若低于 32.15 g：在配方窗口内小步提高 `holdPressureSP`（优先）或 `holdTimeSP`。
3. 若高于 32.85 g：反向小步回调。
4. 每步写入后等待 ≥τ+10s，回读克重与模温、飞边、缺陷率。
5. 达到目标窗口后停止调参，输出证据；不得连续越界或超步长。

## 6. 安全与验收

- 量程/步长/60s 写入间隔由平台四层限界强制执行。
- 所有写入经 HITL 审批并落审计；Agent 不得绕过。
- 验收：V1 数采落库、V2 越界拒、V3 合法写回环、V4 配方映射、V5 频道绑定、V6 受保护线零扰动。
- 模拟闭环：至少 1 次真实写入 + PV 向预期方向移动 + 回读证据。
- 割接演练：仅替换 `inj-main` 的 driverConfig 端点/寄存器到第二套协议兼容设备，治理配置与 Channel 不变；复验 V1/V3。**这是模拟端点切换，不是物理 HIL。**
