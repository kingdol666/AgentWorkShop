## 四、设计思想评估：这个 idea 好不好？

**结论：方向正确且有差异化，但目前是“可试点”而非“可无人值守产线”。**

### 4.1 真正好的地方（值得坚持）

1. **把“协作”和“交付”分开**：Channel 管团队/工具/会话，Project 管 WBS/交付物/验收。多数多智能体框架只有对话，没有交付合同；这是面向产业的关键抽象。
2. **工具即能力授权**：节点绑定（DAQ/DCW/配方）+ 项目内 `write_intent` + HITL，把“Agent 能做什么”变成可审计的配置，而不是 prompt 约束。
3. **harness 无关**：14 引擎注册表 + 构造契约 + AgentBlock，避免被单一模型/CLI 锁死；这在产业侧很重要（客户现场引擎不统一）。
4. **治理闭环**：写动作有回读、有快照、有 60s/300s 节拍闸、有 L1/L2 双签，这套“工业变更控制”语义比“让 Agent 自主写 PLC”成熟得多。
5. **证据文化**：每个阶段都落 JSON/截图/审计事件，可复验、可追责——产业落地最缺这个。

### 4.2 结构性隐忧

1. **状态机复杂度高于业务复杂度**：Project/WorkItem/Attempt/Session/Clone/Instance 五层对象，叠加 completed 项目不释放频道绑定（本轮 CAL-3 首次 409 即此因），运维心智负担大。
2. **缺少持久化工作流语义**：没有 saga/outbox/补偿事务；派发、提交、验收靠事件与轮询拼接，跨步骤失败靠重试与人工对账。
3. **节拍闸是“事后拒绝”而非“事前排程”**：300s/60s 闸会把计划打回，Agent 只能等待/重试；生产上应由调度器预留时间窗。
4. **仍是“演示级默认值”风险**：mock leader 广泛存在；真实模型能力/成本未纳入验收（CAL-3 的规划质量未做统计评估）。
5. **可观测性偏“事件账本”，缺 SLO**：有审计事件，但缺 stuck 实例、队列积压、harness 崩溃率、写失败率的告警与看板。
6. **多租户与安全边界**：插件宿主、密钥、跨项目隔离、Mimosa 扫描未完成，离“多工厂 SaaS”还有距离。

## 六、面向产业落地的优化意见（按优先级）

**P0（上产线前必须）**
1. 绑定生命周期：Project 完成/归档自动释放 Channel 绑定；重跑前可显式解绑（本轮已手工验证可用）。
2. 工作流持久化：为 Project 状态迁移引入 outbox + 幂等消费 + 补偿（saga），消灭“卡死靠人工对账”。
3. 节拍感知调度：调度器维护每条线的写时间窗/配方试验配额，派发前预留，而不是执行时被闸拒绝。
4. HITL 意图幂等/TTL：意图在 dispatch 即消费的语义要显式化；重试自动重新申请并保留 digest 稳定。
5. 进程与实例监管：harness 崩溃自动重启 + 退避 + 单实例配额；stuck 实例超时回收。
6. 运维面：SLO 看板（派发成功率、写确认率、实例崩溃率、队列时延）+ 告警；备份/恢复演练（P4）与成果提交窗口（P6）落地。

**P1（试点期）**
7. 环境分层：mock / 仿真 / 实线 强制打标，禁止 mock leader 进入产线项目（已有部分校验，继续收紧）。
8. 能力注册表版本化：工具 schema/驱动版本与配方绑定，变更走审批。
9. 协议一致性套件：OPC UA/MQTT 写确认、回读、断线重连、时钟漂移的自动化验收。
10. 数据治理：历史编码清理、数据集血缘、保留策略。
11. 多租户/RBAC/密钥托管/插件沙箱。

**P2（规模化）**
12. 模型评测与灰度和影子模式：优化建议先 shadow，再 assist，再 bounded auto。
13. 成本/预算控制（每项目 token/时长配额）。
14. 数字孪生保真度校准与仿真-实线偏差监控。
15. 边缘部署（工厂内网）与离线降级。

## 七、结论

- **系统能力**：产线工具集成调度、跨频道协同、多会话隔离、多 harness 适配、HITL 受控写、四期递进闭环，均在 main 构建上真实通过（CAL-3 78/78，多会话 20/20，多 harness 24/24，Project 58/58，UI 12/12）。
- **设计思想**：抽象层次选对了（协作面/交付面/能力面/治理面分离），具备产业差异化；但当前实现复杂度与运维成熟度还不支持“无人值守”。
- **建议路径**：先在**非安全回路**做 4-8 周试点（只读诊断 + HITL 建议 + 人工执行），用真实 KPI 校准；再开放 bounded auto；P0 项清零后再谈产线常驻。
