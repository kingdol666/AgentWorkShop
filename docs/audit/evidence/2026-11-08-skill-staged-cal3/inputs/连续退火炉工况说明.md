# 3# 连续退火炉机组（CAL-3）工况说明

> 文档版本 V2.0 · 2026-11-08 · 冷轧厂工艺科 · AgentWorkShop 智能作业一期输入

## 1. 机组概况

- 机组：3# 连续退火炉（CAL-3），冷轧带钢连续退火
- 产品：冷轧低碳钢带（厚度 0.5~1.2 mm，宽度 900~1250 mm）
- 正常工艺：炉温一区 780℃ / 二区 800℃，带速 90 m/min
- 质量要求：**抗拉强度 480±20 MPa**，**延伸率 ≥18%**，出口温度 680±10℃
- 当前问题：抗拉强度批次间波动 ±45 MPa（超规格线），出口温度波动 ±18℃；操作员凭经验调温，无量化依据

## 3. 作业目标的阶段性（重要：分期推进）

工艺科明确要求**分四期推进，逐级放开自动化程度**，每期验收通过后才进入下一期：

| 期 | 目标 | 自动化边界 |
| --- | --- | --- |
| 一期 | 强度波动与出口温度波动的**数据诊断**（找相关因素、留证据） | 只读，零写 |
| 二期 | 基于诊断结论做**小步治理试验**（HITL：每步人工批准） | 写 SP，逐动作审批 |
| 三期 | 用治理后的工况数据**构建训练数据集**（为模型化做准备） | 零写（只建数据集） |
| 四期 | 模型化后的**受控自主优化**（有界小步激励，无需逐步审批） | 有界自主，越界即停 |

## 4. 工艺约束（安全规程）

- 炉温单步调整 **≤10℃**（一区/二区同）
- 带速单步调整 **≤5 m/min**
- 两次炉温调整间隔 **≥5 分钟**（防热冲击与振荡，平台试验节拍同值）
- 二区温度不得低于一区（工艺上二区为均热段，误配会导致性能不合格）
- 出口温度低于 650℃ 时禁止提速

## 5. 期望交付

- 先用**模拟环境**验证整条链路（不直连真机），模拟通过后再割接
- 分岗位：数据分析、工艺控制、模型训练、优化寻优各由不同 Agent 承担
- 四期作业串成一条**项目**，前置期完成才放行后续期
- 交接时需要：接入清单、绑定关系、审批策略、回退方式
