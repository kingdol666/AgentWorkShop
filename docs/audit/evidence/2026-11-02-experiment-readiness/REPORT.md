## 0. 结论(先说)

1. **实验流程与纪律是论文级的**:预注册、两套环境态(B/P)、阴性对照、分母单列、双跑复现、数字—产物—runId 账本,均已落地。
2. **最终批次结果是完整的一批**:集成流水线 **77/0/0 ×2(REPRODUCIBLE)**;场景×协议准入 **244/244 受理、243/243 拒绝、236/236 回读**;优化对照 **C0 0/15 vs C1 15/15**(3 场景×5 seed);四臂+生产态五层消融;审批/授权配置级路径检查。
3. **但"系统全部功能"没有被实验全覆盖**:实验只覆盖"场景配置→数采→治理写→过程观测→拦截"这条主路径。Agent 自主多轮(C3)、团队协作(P12)、AML/本体/IDD-RAG/插件/MCP/异步面,要么只有回归/演示证据,要么完全没有进入论文实验矩阵。
4. **TII 可用性**:**按论文当前"系统集成 + 受测路径"的克制口径,现有证据自洽、可投**;但按 TII 审稿强度,大概率 **Major Revision**——缺活体 Agent、缺基线控制器、缺审批单机制消融、缺统计功效、缺实体/HIL。
5. **"完整多轮"目前是脚本策略的多轮**(C1:injection 12 写/17 轮、wwtp 56/59、anneal 41/50),**不是 LLM Agent 的多轮**;这是最需要补的一块。

## 2. 实验流程(为什么可信)

- **S0 冻结**:commit/lockfile/Node/模型/seed/阈值写 `preregistration.json` + SHA256,看结果前冻结;
- **S1 静态层** → **S2 B 态 E1/E4** → **S3 B 态 E2** → **S4 P 态 E3/五层** → **S5 复现**(同命令二跑 + compare) → **S6 台账派生** → **S7 论文落数**;
- **两套环境态不可混**:B 态为 bench 模式(步长/60s/保持窗被全局豁免),P 态为生产态;混用即整包作废;
- **铁律**:每个数字→block+runId+产物;无阴性对照的阳性不算证据;跨 run 只报描述;判据只取独立数据面;状态由产物派生。

## 6. 现在能写什么 / 不能写什么

**能写**:配置模型、共享分发、路由复核、证据分离、场景×协议准入、治理写拦截、确定性策略的闭环对照(描述性)、四臂/五层消融、复现性。
**不能写**:活体 Agent 自主优化、多 Agent 团队优越性、审批有效性、Harness 可替换、控制器优越性、物理安全。

**当前论文已按此边界写作**(evaluation/discussion 均明确 "not a live Agent / not controller superiority"),因此**可以投**;若目标是减少 Major Revision,优先补 P0 两项。
