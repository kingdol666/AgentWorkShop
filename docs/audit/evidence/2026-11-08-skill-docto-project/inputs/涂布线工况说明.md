# 2# 挤出涂布产线工况说明（交付 AgentWorkShop 接入）

> 文档版本 V1.2 · 2026-11-08 · 工艺科提供 · 作为 AgentWorkShop 一期接入输入

## 1. 产线概况

- 产线：2# 挤出涂布线（内部代号 CSL-2），产品：PE 涂布膜（定量 20~45 g/m²）
- 基材：60 μm BOPP，正常车速 80~150 m/min
- 控制系统：西门子 S7-1200（Modbus TCP 网关，IP `192.168.10.21:502`，unitId 2）
- 当前班次问题：涂布定量波动 ±3 g/m²（目标 ±1.5），温度与定量相关性待查

## 3. 作业目标

1. 涂布定量稳定在 **28±1.5 g/m²**（当前 ±3）——一期核心目标；
2. 温度/压力异常要能自动诊断并给出证据；
3. （二期）希望多岗位协同做参数寻优与模型构建。

## 4. 约束

- 涂布头温度单步调整 **≤3℃**（工艺规程 7.2 条）；
- 收卷张力单步调整 **≤10N**；
- 采样：温度类 2s/条，其余点位按现行 DCS 周期；
- 接入期间不得影响生产：只读为主，写操作按规程审批（manual）。

## 5. 与 AgentWorkShop 的对接期望

- 先用模拟环境验证整条链路（不直连真机）；
- 数据分析、工艺调优岗位希望由不同 Agent 承担；
- 交接时给出：接入清单、绑定关系、如何回退。
