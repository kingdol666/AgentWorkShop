05

诚实边界与遗留

不宣称未验证项

本报告不做以下宣称

  • 设备层是模拟孪生(plc-node-simulator,OPC UA/Modbus 真实协议但虚拟物理)。未在物理 PLC 上执行;割接按手册六步清单另行执行。
  • 门禁阈值经设置面校准(G3 0.35、G4 300 行):ABAB 激励 run 间存在天然分布差异 + 演示数据集偏小。这是「按场景校准门限」的正当用法,但与默认生产阈值(0.2/500)不同,已如实标注。
  • 模型增益 0.0354 vs 物理真值 0.052(偏差 32%):线性模型在噪声/滞后下的合理近似;用于寻优方向足够,不用于精度宣称。
  • T3 的 hitl/auth-matrix 未随本轮实例:两脚本默认写死 :3000,本轮隔离实例为 :3975;属测试夹具的端口适配问题,不是产品缺陷。
  • 训练迭代 6 次失败全留痕:byRun 防泄漏切分 × 激励分布不一致的真实工程摩擦;解法是「所有 run 同款激励」,不是放宽数据纪律。
  • 无人值守仍为 NO-GO:受控试点 GO —— 写控联锁、HITL、台账、可辨识性门在多轮负例中表现正确;但物理割接、长周期稳定性、异常恢复演练尚未完成。
