摘要：# 《星际撤离》策划案（精简版）

**概念**：驾驶撤离穿梭机 ARK-7，在崩解星域救起逃生舱，攒够配额后穿过跃迁门。单文件 HTML，3 关，单局 6–9 分钟。

**循环**：走位射击清障 → 接触逃生舱营救（连击↑）→ 配额达成开启跃迁门 → 入门结算 → 三选一升级 → 下一关。船体归零失败，三关通关胜利。

**键位**：WASD/方向键移动；Space/J/左键开火；Shift/K 冲刺（0.16s，无敌 0.3s，冷却 2.2s）；Esc/P 暂停；M 静音；R 重开。触屏拖动移动并自动开火（可选）。

**玩家**：船体 100，移速 430，判定半径 12；双管子弹 12 伤/154ms/950 速；热量每发 +9，满 100 锁火，降至 30 恢复。逃生舱下落 90–130px/s，接触即救、+1 人；漏舱清连击并扣结算分。连击窗口 6s，倍率 1.0/1.25/1.5/2.0/2.5。

**3 关**：
1. 残骸带（暖橙）：配额 12，par 85s；小行星为主，12s 后无人机、38s 后追猎者，教学关。
2. 离子风暴（青紫）：配额 15，par 100s；20s 起每 12s 交替雷柱（预警 1.5s、宽 70、伤 14）与离子风（3s、±900 加速度），叠加磁雷/无人机。
3. 虫群封锁（毒绿）：配额 18，par 120s；幼体波+追猎者+磁雷；配额达成后虫巢核心（900HP）破盾，环形弹+持续产崽，击毁后开门。

**计分与胜负**：营救 100×倍率；击毁小行星 20/60、无人机 140、追猎者 220、磁雷 40、幼体 60、核心 2500。关卡结算=营救+击毁+500 基础+时间奖励 min(1000,max(0,(par−耗时)×25))+船体×8−丢舱×50。总分评级 S≥20000/A≥14000/B≥9000。升级 5 选 3：回血 40、射速 +18%、移速 +12% 且冲刺 CD −25%、拾取半径×2、上限 +25。配额达成且入门过关（L3 还需击杀核心）；船体 0 失败。GAMEOVER/VICTORY 按 R 全量重置回第 1 关，保留最高分（localStorage try/catch）；失焦自动暂停。

**美术**：纯 Canvas 矢量+粒子，无外部素材；深空底、1px 细线、霓虹强调色，三关分别暖橙/青紫/毒绿；飞船楔形+双尾焰，逃生舱胶囊+信标，敌人几何剪影；命中火花、爆炸环、震屏、冲刺残影；粒子≤300。

**数值表**：

| 冲刺 | 0.16s / 冷却 2.2s |
| 子弹 | 12 伤 / 154ms / 950 速 |
| 热量 | +9 每发；32/s 冷却；≤30 解锁 |
| 配额 / par | 12/85s、15/100s、18/120s |
| 敌人 HP | 小行星 24/60、无人机 36、追猎者 48、磁雷 12、幼体 12、核心 900 |
