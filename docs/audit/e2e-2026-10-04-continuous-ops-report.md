## 四、HITL 设计验证结论(manual 模式)

1. **每次下发必带人可读理由 —— 现在是强制的**:recipe_propose 每参数必填 basis(为什么这样调)+ exp_ref(证据引用),缺失直接拒收;recipe_update/rollback/trial/apply 的 reason/hypothesis 全部必填(本轮修复 #1 补上最后缺口)。实测审批卡全部带"数值+时间窗+点位"证据链,产线专家可直接核对
2. **拒绝→吸收→重提环成立**:场景 B 三次拒绝(步幅规程/证据补齐)后重提卡质量显著提升;场景 A 方向性错误(向下收敛)经人工反馈+实时 steer 后纠正为向上
3. **人工附言随回执回流**:工况变更告知、规程约束均被 Agent 逐字吸收进后续方案
4. **fail-closed 保持**:审批超时=拒绝;300s 节拍窗拦截直发;停线产线提案快速失败(上轮矩阵,本轮回归)
5. **人工验收不缺席**:lead 完成前独立复核(场景 B 15.68 复测);worker/lead 双面交叉判定口径一致(场景 C 203.27 vs 202.99,桶宽差 0.3℃ 内)
