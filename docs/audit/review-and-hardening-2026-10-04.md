## 二、本轮 P0 落地(b8e7449 + 2a215f9)

1. **覆盖集下发语义**(安全):`applyRecipe` 提供 overrides 时只写声明节点 —— 消灭"两参试验顺带把 zone1 写向旧值"类事故(场景C 实录);无 overrides 保持整批语义
2. **lead 产线管理工具**:`line_start`/`line_stop`(仅频道 lead、恒 HITL、reason 必填、频道绑线锚点 1:1)+ `line_status`(只读)—— 产线启停/批次窗口管理正式进入 Agent 工具面
3. **根任务判重**:同频道+同收件人+归一化同标题的非终态根复用(终态不参与,保留同标题重跑)
4. **HITL 幻影清账**:`sweepPhantomHitl` 以内存 registry 为 live 权威,DB 残留非终态待办清为 failed
5. **未知驱动 kind 显式报错**(不再静默采 mock 数据)
6. **driverConfig 凭据脱敏**(password/secret/token → '******';持久化与驱动内部不经过)
7. **legacy 工具面瘦身**(孪生/训练/优化族与分发守卫同口径摘除;73→60 工具,11K→8.9K tokens)
8. **单实例锁心跳**:锁被接管即自杀退出 + pid 指纹认 dev-guard —— 根治"孤儿 dev 进程与 prod 共写数据目录"(本次实测:孤儿用旧内存列表刷盘,把新建数控节点从 dcws.json 抹掉,即 C3 Agent 上报的"墓碑矛盾"真凶)
