## 3. 与计划的偏差（需知悉）

1. **A4 工具面**：计划写「`search_memory` 增 scope=line/product/global」——已实现（含 `scope_key`），但跨频道授权放在 manager 层（`AgentWorkspace.searchSharedExperience`），而非记忆层，避免记忆层耦合频道归属校验。
2. **B3 晋升审批**：计划要求「镜像 aml_model_promote 的 HITL 审批」。v1 实现为 **owner/admin 经 REST 人工触发**（人本身即审批人），未接入 `project_approvals` 表。理由：经验晋升不改变产线状态，走项目审批会污染项目账本；Agent 工具面不可达已满足「Agent 不能自批」。
3. **C4 指标来源**：`evaluateCriteriaChecks.metrics` 目前无生产调用方供数——`metric.*` 判据在有独立指标前一律阻断（fail-closed）。**接入点= WP-C1 独立验证器**（其产出的回读/DAQ 值应传入）。
4. **Gate-1A 的「真实双频道 + 真 LLM」实机演练**：以离线确定性验收（`scripts/acceptance-rsi-stage1.ts` 13/13）与既有 live 套件覆盖；未在本轮执行带模拟器的全 live 演练。
5. **D3/D4/D5 合并一个 PR**（#128）：三者同属 Stage-1D 收口且互不重叠，合并以省 CI 周期，PR 内逐项列出。

## 7. 范围说明与已知限制（必须知悉）

1. **C1 是「独立回读」，不是「fresh-session 探针频道」**：判定用设备实时回读值（非指令值）对照台账意图值，已闭合“Agent 自报 vs 设备事实”的核心断点，并接入 L1 checks 与 C4 指标源（`task_id` 归属）；但未 spawn 独立 observe 实例（需运行时装配 + 会话隔离，属后续工作）。`inconclusive` 语义已在代码与测试里保证“不等于 pass”。
2. **B2 的 live 配对模式未在本环境执行**：统计与门入参链路已完整实现并自检（8/8，含 t 分布真值对齐）；真实配对需平台 + 场景 runner（`--cmd-a/--cmd-b` 契约已定义）。文档状态已更新为 `IMPLEMENTED(lite)` 并写明 D8 夹具要求。
3. **`validated` 晋级的可达性（P1 设计缺口）**：反射器按“一任务一条经验”写入，而门要求 ≥2 个独立 taskIds → **自动产物永远停在 candidate**，实测（运行实例 4 个真实任务 → 4 条 candidate，晋升被拒「独立任务样本不足：1/2」）。当前可行路径：人工/脚本把同主题证据合并成一条（Phase A 演示）后再晋升。
   建议后续实现**确定性证据合并**（同一 line + 同一 scopeKey + 同极性的经验，按人工确认后合并 taskIds），或提供 `POST /memories/experience/merge` 策展端点。
4. **B4 的“劣化自动回滚”当前是人工触发**：`rollbackProfile` 是确定性执行面（选中上一版本、单 active、审计入表），但触发面为 owner/admin REST，未接“B2 runner 自动判定劣化 → 自动 retired+复位”。理由：自动回滚会改变 Agent 行为面，写面必须过人；待 B2 live runner 落地后再接自动触发。
5. **Gate-1A 的 A-3 数值口径未做全 live**：离线验收 13/13 + Phase B 4 任务实机已覆盖三触发/跨频道/预算/隔离；计划要求的“CAL-3/WWTP-4 双频道 5 轮 → 经验 ≥8、跨频道命中 ≥3”需专用场景 runner，本轮未执行。A-6 的 `test:e2e-line`（44/44）与 `test:api-live`（71/71）已在隔离实例通过。
6. **Mimosa 安全扫描**本轮仍为 inconclusive（`scanner_enobufs`）→ 不宣称安全。

`recipe_trial`/`recipe_propose`/`recipe_apply` 的 `agentTrialMeta` 补 `channelId`（缺调用上下文时按
agent 成员反查）。修复后 live E2E 的 C1 归属与 L1 阻断均实证通过。

**仍存操作约束（未改产品语义）**：项目任务实例 Channel 只继承 AML profile（D5），**不继承 line 绑定**；
现场对实例频道执行工业写前需显式 `PUT /channels/:id/line`。是否让实例自动继承模板频道 lineId 属权限面
变更，留待后续评审（本轮 E2E 以显式绑线通过）。
