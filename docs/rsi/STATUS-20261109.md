## 3. 与计划的偏差（需知悉）

1. **A4 工具面**：计划写「`search_memory` 增 scope=line/product/global」——已实现（含 `scope_key`），但跨频道授权放在 manager 层（`AgentWorkspace.searchSharedExperience`），而非记忆层，避免记忆层耦合频道归属校验。
2. **B3 晋升审批**：计划要求「镜像 aml_model_promote 的 HITL 审批」。v1 实现为 **owner/admin 经 REST 人工触发**（人本身即审批人），未接入 `project_approvals` 表。理由：经验晋升不改变产线状态，走项目审批会污染项目账本；Agent 工具面不可达已满足「Agent 不能自批」。
3. **C4 指标来源**：`evaluateCriteriaChecks.metrics` 目前无生产调用方供数——`metric.*` 判据在有独立指标前一律阻断（fail-closed）。**接入点= WP-C1 独立验证器**（其产出的回读/DAQ 值应传入）。
4. **Gate-1A 的「真实双频道 + 真 LLM」实机演练**：以离线确定性验收（`scripts/acceptance-rsi-stage1.ts` 13/13）与既有 live 套件覆盖；未在本轮执行带模拟器的全 live 演练。
5. **D3/D4/D5 合并一个 PR**（#128）：三者同属 Stage-1D 收口且互不重叠，合并以省 CI 周期，PR 内逐项列出。
