**本轮修复的真实问题**
1. `/api/system/timezone` 只认 Bearer，而设置页两处裸 `fetch/$fetch` 未带头 → 401 + 重试风暴（134 errors / 122s）。改为统一 `apiFetch`（自动 Bearer），401 清零、加载恢复正常。
2. 3D 台 `.dock-toggle` 的隐藏规则只写在其它组件的 scoped 样式里，本组件在桌面档无样式 → 浏览器默认白块按钮横在舞台上。已在组件内声明桌面隐藏。
3. 已知残留：/settings 1 条 hydration 警告（页面渲染正常、无功能影响）；仪表盘偶发「写入 undefined → undefined」toast（事件载荷缺字段的瞬时文案）。

## 四、前端设计评价（专业视角）

**总评：8.5 / 10 —— 优秀、产品级，具有鲜明的工业控制室身份，与「产线监控 + Agent 编排 + 数据分析」场景高度匹配。**

**做对了什么**
1. **设计系统完整且克制**：绿 #35e0a0 / 青 #41c8f4 / 深海军蓝的单一色相族 + 玻璃面板 + hairline/刻度尺母题；标题用衬线、数据一律等宽 tabular，编辑感强，不像模板站。
2. **信息架构贴合监控岗**：仪表盘「KPI 条 → 趋势/状态图 → 产线卡」自上而下；页头统一 kicker+大标题+度量线；数采/写控/配方/批次等域术语与结构对得上真实工位心智。
3. **空间化孪生是差异化亮点**：3D 舞台 + 设备资源库 + 右轨设备状态/事件流，把「Agent 团队在产线上作业」具象化；频道挂载后可见设备与实时事件。
4. **一致性与可达性**：按钮/徽标/卡片/表格词汇全站统一；桌面/图标轨/抽屉/底部 sheet 四形态响应式；触控目标 ≥40px；深浅色 token 化；中英双语。
5. **数据可视化节制**：仪表盘图表去网格、语义配色；未堆无意义统计装饰；空状态有指导文案（孪生空场景即典型）。

**还可以更好的地方（按影响排序）**
1. **密集页的可扫读性**：数采（66 节点）/日志（数万字符）/产线操作是「表格墙」，缺分组折叠、摘要卡与关键指标前置；建议加「按产线/状态分组 + 首屏摘要条」。
2. **孪生场景需要手工搭建**：新工作区是空舞台，价值取决于布景投入；若能按产线拓扑自动生成初始布局（设备/流向/工位），演示与上线成本会大幅降低。
3. **瞬时提示质量**：个别 toast 出现 `undefined` 或插件样本噪音（line-sentinel），移动端会短暂遮挡内容；建议事件载荷兜底文案 + 插件提示改角标。
4. **台账摘要可再收纳**：行内展示完整结论导致列表很长；可用 2–3 行截断 + 详情展开（当前用「详情」保证信息完整，属取舍）。
5. **/settings 的 hydration 警告**：清理后可达「全站 console 全零」，属工程卫生项。
