# 标准产线开发文档 —— 注塑成型二线(精密结构件,injection-line 设备族)

> 按《标准产线开发文档》模板填写;skill `aw-line-onboarding` 唯一输入面:
> `node scripts/onboarding/onboard.mjs inj2-onboard.json --smoke`
> **信号面声明**:本线与在跑的注塑一线(ln-5b12e11a)共用同族物理设备;一线已占用
> 保压压力/保压时间/注射速度(OPC UA :5843)、模温机(RTU :15052/40021)、螺杆转速(:16052/40029)。
> **本线配方与冒烟全部选用与一线不相交的写点**(机筒四区/锁模力/冷却水),skill 的跨线写点
> 冲突预检会硬闸任何撞线配置(2026-10-10 新增,阴性验证已过)。

## 1. 产线概况与作业流程

注塑成型二线(精密结构件):原料干燥 → **机筒四区加热塑化** → 注射 → **保压** → **锁模约束** → **冷却水路定型** → 顶出 → 在线质检(克重/飞边/缩痕/尺寸偏差/周期/壁厚轮廓/表面 CCD)。模拟器设备族 `injection-line`(增量共存)。

## 2. 作业目标与内容(本期)

| 项 | 内容 |
|---|---|
| 目标 | **克重窗口稳产**:制品克重落在 32.5±0.5g 合格窗,飞边/缩痕不劣化 |
| 本期作业 | 闭环优化找工艺区间(scenario=optimize):机筒温度 × 锁模力 × 冷却水温度的窗口寻优,克重复测判向 |
| 治理 | HITL 强制审批(配方 manual);越界/超步拒绝 |
| 约束 | 机筒温度单步 ≤5℃;锁模力单步 ≤80kN;冷却水单步 ≤1℃;飞边>3% 或缩痕>4% 即回退 |

## 4. MES API

本期不接(克重窗口纯 PLC 闭环);二期按 skill「MES 双模式」扩展。

## 5. Channel 与任务需求

| 项 | 需求 |
|---|---|
| 场景 | optimize(hitl_governed) |
| 频道模板 | `chtpl-generic-optimize-default` |
| 绑定矩阵 | 工艺工程师 recipe manual(基线配方 4 参数);数据分析师 daq auto(全部 13 点) |
| 插件 | idd-closedloop-bridge + rag-bridge |
| 种子任务 | 「建立二线基线档案并完成一轮克重窗口寻优:目标 32.5±0.5g;机筒/锁模/冷却水小步 ≤各步限,每步 settle≥60s;飞边>3% 或缩痕>4% 即回退;达标=克重连续 3 窗在窗且质量不劣化;每轮 kb 沉淀」 |
| 基线配方 | 「二线克重窗口基线配方」:机筒区2 245℃ · 机筒区3 248℃ · 锁模力 1500kN · 冷却水 25℃ |
