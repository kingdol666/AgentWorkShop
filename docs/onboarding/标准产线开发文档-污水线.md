# 标准产线开发文档 —— A2O 污水生化处理线(wwtp-line)

> 按《标准产线开发文档》模板填写(模板结构见 docs/onboarding/标准产线开发文档-连续退火线.md)。
> 本文档为 skill `aw-line-onboarding` 的**唯一输入面**:一键接入
> `node scripts/onboarding/onboard.mjs wwtp-onboard.json --smoke`。

## 1. 产线概况与作业流程

A²/O 活性污泥法污水处理线:粗格栅 → **厌氧区 → 缺氧区 → 好氧区(曝气风机供氧)** → 二沉池
(**加药** NaOH/PAC 除磷调 pH;**内回流**脱氮;**污泥回流 + 排泥**维持泥龄)→ 深度过滤 → 出水在线监测(COD/氨氮/总磷/pH/浊度)。模拟器设备族 `wwtp-line`(增量共存)。

## 2. 作业目标与内容(本期)

| 项 | 内容 |
|---|---|
| 目标 | **出水达标前提下降耗**:COD/氨氮/总磷达标的条件下,降低曝气与加药量 |
| 本期作业 | 闭环优化找工艺区间(scenario=optimize):基线建档 → 曝气量/加药量微步寻优 → 质量复测 → 沉淀经验 |
| 治理 | HITL 强制审批(配方绑定 manual);越界/超步一律拒绝 |
| 约束 | 风机频率单步 ≤1.5Hz;加药单步 ≤6 L/h;回流单步 ≤8%;出水 COD>80 或氨氮>8 即回退 |

## 3. PLC 点位连接表(20 点,五协议族;来源=设备 export)

| 设备 | 协议/端口 | 信号(SP 写控粗体) | 量程 | 单步 |
|---|---|---|---|---|
| 曝气风机 | Modbus TCP `:16054` u1 | **风机频率SP**(40021)/ AirPress(40001)/ DO(40003) | 20~50 Hz;20~90 kPa;0~10 mg/L | 1.5 |
| 加药站 | OPC UA `:5844` | **NaohDoseSP**/**PacDoseSP**;NaohFlow/PacFlow | 0~120 / 0~90 L/h | 6 / 4 |
| 回流排泥 | Modbus RTU `:15054` u1 | **内回流比SP**/**污泥回流比SP**/**排泥量SP**;MLSS | 20~180%;30~120%;50~400 m³/d;1k~8k mg/L | 8/4/17 |
| 进水 | MQTT `:18830` | CodIn(`aw/wwtp/codin`,jsonPath data.cod)/ Nh3In(data.nh3);**InflowSP**(`aw/wwtp/inflow/set`,jsonKey setpoint) | 100~900;10~80 mg/L;400~1600 m³/h | 60 |
| 出水监测 | HTTP `:4010/sim-http/wwtp-effluent-http/` | CodOut/Nh3Out/TpOut/PhOut/Turbidity(标量 jsonPath=value);**DoProfile(向量,jsonPath=points,24 点)** | 0~300;0~60;0~8 mg/L;4~11;0~60 NTU;0~10 mg/L | — |
