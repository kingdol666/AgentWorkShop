# 标准产线开发文档 —— 连续退火线(anneal-line)

> 文档定位:**产线开发标准模板**(用户提供给 AgentWorkShop 的唯一输入面)。
> 配套 skill:`aw-line-onboarding`(产线接入与作业频道锻造)—— 本文档按其输入识别五分类组织:
> PLC 点位表(①)/ OPC UA 节点表(②)/ MQTT 主题表(③)/ MES REST 文档(④)/ 产线背景与作业需求(⑤)。
> skill 依据本文档自动完成:点位提取 → 连通性预检 → 产线供给(线/节点/上下限/配方)→ 场景化频道锻造 → V1-V6 验收。

---

## 1. 产线概况与作业流程

- **产线**:连续退火线(冷轧板带连续处理),模拟器设备族 `anneal-line`(增量共存,不动既有产线)。
- **工艺流程**:放卷 → **加热段(均热三区,区权 0.25/0.35/0.40)** → 炉内传动(线速)→ **冷却/过时效段** → 保护气(H₂/N₂ 混合,露点与 H₂ 占比可控)→ 在线质检(硬度/拉伸/屈服/晶粒度/表面/板形)→ 收卷。
- **产品**:冷轧板带;质量指标以在线质检为准,工艺窗口由均热温度 × 线速 × 过时效共同决定。

## 2. 作业目标与内容(本期)

| 项 | 内容 |
|---|---|
| 目标 | **质量窗内产能最大**:硬度落在 125~165 HV 合格窗的前提下,尽量提升线速 |
| 本期作业 | **闭环优化找工艺区间**(scenario=`optimize`):先建基线档案,再由 Agent 提出均热温度/线速微步,人工审批后下发,读 Δ 判向,收敛出"质量窗内的线速上沿" |
| 治理 | HITL 强制审批(hitl_governed):配方绑定 **manual** 起步,每一步下发必须人工批准 |
| 约束 | 均热区单步 ≤12℃;线速单步 ≤8 m/min;过时效单步 ≤10℃;冷却档位单步 ≤5%;H₂ 占比单步 ≤1%;越界一律拒绝 |

## 4. MES API 说明(REST)

| 项 | 值 |
|---|---|
| BaseUrl | `http://127.0.0.1:15060` |
| 认证 | 请求头 `x-api-token`;**凭据走 secretRef 零明文**:driverConfig 只写 `secretRef: MES_ANNEAL`,真实 token 放环境变量 `AW_MES_MES_ANNEAL_TOKEN` |
| 字段清单 | `GET /api/v1/fields` → melt_pressure(MPa)/ melt_temp(℃)/ line_speed(m/min) |
| **区间取数(本期接入)** | `GET /api/v1/series?fields=<a,b>&from=<ISO>&to=<ISO>&interval=<秒>` → `{data:{rows:[{ts, values:{<field>:v}}], nextCursor}}`;**分页必须配 nextCursorPath=`data.nextCursor`**(漏配只取第一页) |
| 质量快照 | `GET /api/v1/quality/thickness`(本期不接,预留) |

### 4.1 接入方式选型(skill 判据)

本期要"按需回看历史区间、多字段+时间段+间隔聚合" → **参数直取模式**:建 mes-rest **写控面节点**(kind=dcw,driver=mes-rest)+ historyMap;`query.fields` 按节点声明字段,`from/to/pageSize/cursor` 平台自动注入;内网地址须显式 `allowPrivateHost:"true"`。镜像入库模式(时序库常采)本期不用,留作二期。

- 节点 A「MES温度序列(melt_temp)」:historyMap.query.fields=`melt_temp`,valuePath=`values.melt_temp`,tsPath=`ts`,rowsPath=`data.rows`,nextCursorPath=`data.nextCursor`
- 节点 B「MES压力序列(melt_pressure)」:同构,fields=`melt_pressure`

## 5. Channel 与任务需求

| 项 | 需求 |

## 6. 验收标准(全部满足才可交付投产)

1. **连通性预检全绿**:五个协议族逐驱动 ✅ + MES 直取读 ✅(skill 阶段 2)。
2. **产线供给落袋**:线/19 节点/配方 id 记录在案;上下限+stepLimit 显式配置(四层限界生效)。
3. **V1~V6 全绿**(`verify-line`):数采落库 / 越界写必拒 / 合法写回环 / 配方映射 / 频道绑定 / 受保护演示线零扰动。
4. **真实作业三件**:①PLC 数采五族 2 分钟窗有真值;②MES 区间取数 mes_fetch 拉到 30 分钟窗行数>0 且分页完整;③闭环步:提案 → HITL 人工批准 → **整批下发全部设备证实**(readback-verified)→ 镜像/质检复测响应。
5. **交付说明**:复用/新建清单、绑定矩阵、HITL 策略、回退路径(配方→节点→线逆序)。

## 7. 治理红线(全期有效)

- driverConfig 只来自设备 export/本文档;缺失字段问用户,禁止猜测。
- secretRef 零明文:token 只进环境变量,不进配置文件、不进对话。
- 受保护演示线(ln-d7e0a2a2)只读;非本次创建的资源一律不动。
- 配方下发缺省 manual 逐动作审批;频控 opIntervalMs 缺省 60s,审批锚计时,`emergency=true` 可豁免频控(审批照挂)。
- 模拟器整包替换型预设(film-line/cast-film-physics/biax-line)禁用。
