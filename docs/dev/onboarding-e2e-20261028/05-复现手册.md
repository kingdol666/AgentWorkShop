# 复现手册:文档 → 模拟 PLC → 节点 → Channel → 全链路(逐条命令)

> 前提:仓库根 `D:\codes\ABO\AgentWorkShop`,已 `npm run build`(存在 `.output/`);Git Bash。
> 全程约定:`export AW_BASE=http://127.0.0.1:3105 NO_PROXY='127.0.0.1,localhost'`。

## 第 0 步:隔离实例(铁律:AW_MODE=home)

```bash
mkdir -p /d/codes/ABO/aw-onboard-home-$(date +%Y%m%d)
AW_MODE=home AW_HOME="D:\\codes\\ABO\\aw-onboard-home-$(date +%Y%m%d)" PORT=3105 \
  NUXT_SESSION_PASSWORD='onboard-e2e-20261028-session-pw-0123456789ab' \
  AW_MCP_ENABLED=true AW_TRIAL_INTERVAL_MS=0 \
  node .output/server/index.mjs &> /d/codes/ABO/aw-onboard-3105.log &

# 就绪 + 必须是 fresh(needsSetup:true;若 false 说明误挂共享库,立即停)
sleep 8; curl -s --noproxy 127.0.0.1 http://127.0.0.1:3105/api/users/setup-status

# 首账号注册(只一次;首注册即 admin,后续脚本缺省凭据依赖它)
curl -s --noproxy 127.0.0.1 -X POST http://127.0.0.1:3105/api/users/register \
  -H "content-type: application/json" \
  -d '{"name":"Onboard Admin","email":"admin@awshop.local","password":"admin123"}'
```

## 第 1 步:读文档,提炼点位成蓝图(助手职责;脚本不做文档理解)

输入:`01-接口协议文档-*.md` + `02-工况说明文档.md`。逐点核对:
量程/单位/精度/单步上限/SP-PV 判定/采样周期;缺任何一项**停下来问产线,禁止猜**。
产出:`03-blueprint.json`(信号 id、kind:sp/pv、dynamics 因果增益取自文档 §工艺因果)。

## 第 2 步:生成模拟 PLC 接口(aw-plc-sim-twin 模式 B)

```bash
node scripts/onboarding/sim-twin.mjs \
  --blueprint docs/dev/onboarding-e2e-20261028/03-blueprint.json --sim-port 4034
# 通过判据:✔ 设备 coat-machine-1(modbus-tcp,6 信号) + ✔ 孪生 tick 活性(PV 在动)
# 末行 JSON 含 simBase/影子树/设备 id;模拟器自动拉起影子树 ../plc-node-simulator-twin-4034
```

## 第 3 步:export driverConfig(协议面唯一来源,永不手抄)

```bash
curl -s --noproxy 127.0.0.1 http://127.0.0.1:4034/api/nodes/coat-machine-1/export \
  -o docs/dev/onboarding-e2e-20261028/sim-export.json
```

## 第 4 步:合并成语义+协议的统一配置(onboard 输入)

`04-onboard-config.json` 生成规则(见 README §4):`nodes[].driverConfig` = export 对应项;
`min/max/stepLimit/holdIntervalMs/intervalMs/warnLow/warnHigh/templateRef` = 文档语义面;
`recipe.params` = 配方窗口(⊂ 节点量程,尊重安全红线);
`channel.scenario` = 按工况选 optimize/diagnose/tuning;`bindings` = recipe(manual)+daq(auto);
`smoke` = 冒烟参数与步长(≤stepLimit)。

## 第 5 步:一键全流程(预检→供给→锻造→V1-V6→冒烟)

```bash
AW_BASE=http://127.0.0.1:3105 NO_PROXY='127.0.0.1,localhost' \
  node scripts/onboarding/onboard.mjs docs/dev/onboarding-e2e-20261028/04-onboard-config.json --smoke
# 通过判据:逐阶段「✅」;末行 {"summary":true,...,"pass":N,"fail":0};EXIT=0
```

分阶段等价路径(定位问题时用,与一键同配置):

```bash
node scripts/onboarding/test-connection.mjs  docs/dev/onboarding-e2e-20261028/04-onboard-config.json
node scripts/onboarding/provision-line.mjs   docs/dev/onboarding-e2e-20261028/04-onboard-config.json   # 末步自动开 DAQ 总控
node scripts/onboarding/forge-channel.mjs    <provision摘要内联的channel配置.json>
node scripts/onboarding/verify-line.mjs      <verify配置.json>
```

## 清理与重跑

- 幂等:同配置重跑 `onboard.mjs` 直接复用线/节点/配方/频道(指纹),回归零副作用。
- 丢单重跑:平台停线 → 按 配方→节点→线 逆序删除;频道 `DELETE /api/workshop/channels/:id`。
- 模拟器重启:杀 4034 端口属主进程 + 重跑第 2 步(tick 冻结是已知怪癖,POST 修不了,整树重启即愈)。
