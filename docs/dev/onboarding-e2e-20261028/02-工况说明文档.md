# 锂电池涂布产线 · 工况说明与作业需求

> 提供:工艺科 · 日期:2026-10-28 · 用途:AgentWorkShop 作业频道创建依据

## 1. 产线背景

锂电池电芯制造前段**涂布工序**:浆料经涂布间隙挤出到铜箔集流体,经烘干箱干燥后收卷。
涂布厚度是电芯容量一致性的第一决定量,当前由人工经验调间隙/速度/温度,波动大。

## 2. 当前工况

- 产品:NCM811 正极极片,面密度目标对应的**湿涂布厚度 100 μm**;
- 现状:厚度实测 93~107 μm 波动,规格线 92~108 μm,越限率约 6%;
- 白班产量受速度限制,烘干温度长期保守运行在 110℃;
- 张力在提速时经常越上限(>70 N 断带风险)。

## 3. 作业目标(本阶段)

**闭环优化找工艺区间**:在安全约束内,由 Agent 频道做受控试验,
找使「涂布厚度PV 稳定落入 100±4 μm」的间隙/温度/速度组合;允许做试验,试验预算 ≤60 min。

达标判据:厚度均值落 96~104 μm 且连续 3 次复测(每次 ≥2 min)稳定;张力全程 <70 N;
烘干温度全程 ≤145℃;速度全程 ≤35 m/min。

## 4. 治理要求

- 所有工艺下发必须走审批(HITL),测试期由接入工程师自动裁决,**投用由工艺科长在界面放行**;
- 首绑配方一律 manual 档;数据采集绑定可 auto(只读);
- 频道需带知识沉淀(rag-bridge)与诊断闭环(idd-closedloop-bridge)插件。

## 5. 种子任务

对涂布频道派发首项任务:建立厚度基线档案 → 发起带安全限的优化战役 →
按「设计-采集-入算」小步循环逼近目标窗,外推点必须报人工确认 → 收敛后治理下发并沉淀经验。
