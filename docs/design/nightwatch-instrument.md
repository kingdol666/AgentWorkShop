# 夜航仪 · Nocturne Instrument

## 设计哲学(小镇场景与 HUD 的视觉宪法)

夜航仪是一场关于**夜间工业观测**的美学运动:观者像一位夜航机组,俯瞰一片沉睡的工业园区。画面里没有白天,没有阳光直射的喧哗;只有仪表世界的秩序——石墨色的夜幕下,一切信息都以刻度、微光与色温说话。它必须看起来像被反复校准过千百次的仪器,每一道光都有明确的读数职责,每一块色彩都经过严苛的配比。这是大师级工装的产物:克制、精确、被苛求过。

**空间与形体**主张"制空的分层":地平线是一条被压抑的钢色微光带,其上是近乎纯黑的夜空,其下是深灰的厂区地面——三层世界的交界必须无缝,雾色即地平线色,地平线色即雾色。厂区地面是 systematic repetition 的宣言:大块的混凝土板以隐忍的拼缝重复铺陈,细网格导引线只在近距离低语,不允许任何一块地面抢走实体的戏。领地平台是地面上唯一的"绘制层"——一层薄薄的领域染色与一圈精确的边界光环,像仪表刻度盘上被点亮的扇区。

**色彩与材质**执行严格的五色配额:夜色石墨(基底)、地平线钢青(过渡)、遥测青 `#4da3ff`(数据/信息)、操作琥珀 `#f5a742`(人的动作与警示前置)、语义绿红(运行正常/故障,仅此用途)。任何游离于此配额的颜色都是杂质——薄荷绿、湖蓝、糖果色一律驱逐。金属与粗糙材质只在环境反射里呼吸,不做镜面表演;发光是语义,不是装饰。

**比例与节奏**遵循"实体为重,标注为轻":角色与设备是画面主角,名牌与铭牌是贴在主角身上的临床标签——等宽字体、发丝描边、左侧一道细数据条,像示波器上的通道标记。气泡是短暂的读数,出现时克制地弹入,按时序消隐。共鸣涟漪只有三种:消息=青,完成=绿,故障=红;没有第四种。

**构图与平衡**要求 HUD 与场景共享同一具身体:面板是悬浮在夜幕上的仪表组,纯色深底、发丝描边、单一投影,永不用框套框、渐变、角标或条纹来堆砌"科技感"。层级只由三种语言建立:字号、字重、色温。留白即仪表盘的哑光区——它让每一个读数都被认真阅读。整个界面应让人觉得:它不是被"设计"出来的,而是被一名夜班工程师用二十年经验**装配**出来的。
