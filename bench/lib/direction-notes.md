# Report Design Direction · direction-notes.md

> huashu-design 三方向门的自治会话适配记录（技能降级模式 #5：检查点问答 → 可审计假设清单）。
> 本会话为无人值守执行，用户已在需求中给定审美方向（"美观好看、论文可视化可发表风格" +
> huashu-design 美化要求），故以本文件落档方向推导，替代交互式选向。

## form 推导五问

1. **叙事角色**：数据报告。Verdict 是 hero（评分/等级/门禁判定首屏可见），证据分层在其下。
2. **观众距离**：1m 笔记本屏幕 + A4 纸面打印（论文附录用）。正文 15px，print 样式单独调优。
3. **视觉温度**：冷静、权威、克制（academic register）。纸白底、墨色字、单一信号绿 accent。
4. **容量估算**：单页长文 + 分节；检查明细用 `<details>` 折叠（默认收起，审计时可展开），
   KPI 网格 6 列（打印降 3 列），阶段表全宽。 thumbnail 草案 3 张验证无溢出。
5. **视觉母题**：**控制室检验记录单**（industrial inspection sheet）——项目设计宪法的控制室
   身份（信号绿/数据青/深海军蓝）降饱和为印刷级油墨色；钢印式 verdict 章、等宽表格数字
   （tabular-nums）、发丝线表格（rules only，无斑马纹）。母题来自内容本身：这是产线治理
   系统的检验报告，记录纸就是它的原生形态。

## 三方向取舍（已评估，未展开初稿的假设记录）

| 方向 | 评估 | 结论 |
|---|---|---|
| A · 控制室检验记录单（纸白+油墨绿+钢印章） | 与项目设计宪法同源，印刷级可发表，反 AI 味 | **选定** |
| B · 深色控制台实时面板（GitHub-dark+霓虹） | 与项目 UI 同源但 huashu 明示为 slop 红线，且不适合论文打印 | 否 |
| C · 极简学术白版（IEEE 双栏风） | 可发表但丧失项目身份，"哪个工作室做的"识别度为零 | 否（B/C 的合理部分已吸收进 A） |

## 反 slop 自检

- 无紫渐变 / 无 emoji 图标 / 无圆角卡片+左彩条 / 无 GitHub-dark+霓虹 glow
- 字体：系统栈（Source Serif 4→Georgia 衬线 display + 系统 sans 正文 + 等宽数字），零 CDN、
  断网可开；不引入 Inter/Roboto 作 display
- 颜色全部来自项目色板的印刷化降饱和（`#0a7d54` 信号绿 / `#8a5a00` 琥珀 / `#a03030` 赤），
  无临场发明色
- 一个细节做到 120%：verdict 钢印章（双线边框 + 大写字距 + 轻微旋转）；其余 80% 保持克制
